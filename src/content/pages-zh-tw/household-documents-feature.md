# 家庭文件管理 App 教學：真正要管理的是「去哪裡找」，不是多複製一份檔案

保單在電子郵件、家電手冊在原廠網站、租約是紙本、維修發票又在另一位家人的手機。這種家庭最需要的通常不是第五個檔案櫃，而是一份全家看得懂、能指出權威原件位置的索引。

FamilyBoard 的「文件」分頁刻意不收 PDF 或照片。它讓你記錄名稱、分類、原始存放位置、關聯設備、複查日期與備註，再把這份索引留在目前瀏覽器。這個設計可以減少重複檔案與版本混亂，但也代表你要另外保護原件、索引與備份。

## 先分清楚 App 文件功能和一般整理教學

[家庭文件索引教學](/zh-tw/guides/household-documents-organizer/)著重如何設計分類、寫出家人能重現的位置，以及分享前怎麼降低敏感性。本頁只處理 App 實際怎麼運作：每個欄位會存什麼、卡片如何排序、交接摘要帶出哪些資料，以及跨裝置時要做哪些動作。

如果還沒有整理方法，可先用[家庭文件索引產生器](/zh-tw/tools/household-document-index-generator/)做一份不寫入 App 的草稿；確定分類與位置格式可用，再把需要長期管理的項目建檔。

## 新增文件索引的六個欄位

在[繁中 FamilyBoard App](/zh-tw/app/)開啟「文件」，展開「新增文件索引」：

1. **紀錄名稱：** 必填。寫文件的用途與對象，例如「主臥冷氣購買發票」，不要只抄檔名 `IMG_2048.pdf`。
2. **分類：** 預設「家庭文件」，可改成保固、保險、租約、稅務參考或家庭自訂名稱。App 不會自動統一同義詞。
3. **原始文件存放位置：** 必填。電子資料至少寫服務、資料夾、檔名或可搜尋線索；紙本要寫到盒子、分隔頁或保管人。
4. **關聯資產：** 選填，只能從目前未封存的家庭資產選擇。選到正確設備後，文件匯出與交接就能保留這個關係。
5. **複查日期：** 選填。它是「何時重新確認」而不是自動刪除日，也不是保存期限的法律判斷。
6. **備註：** 選填。適合記待補資料、版本或查核結果，不適合放帳號密碼、完整身分證號、保險箱密碼或復原金鑰。

表單送出後目前沒有卡片內直接編輯或刪除按鈕。需要修正大量資料時，可在設定匯出家庭資料總表 CSV，用穩定 ID 更新後經預覽匯入；操作前先留完整 JSON 安全備份。

## 複查排序現在會告訴你「何時要看」，但不會追著你跑

文件卡依複查日期由近到遠排列，有日期的紀錄放在沒有日期的紀錄前。日期文字會依開啟 App 當天顯示「已逾期」、「今天到期」或本地化後的到期日；沒有日期則顯示未設定。

這個狀態只在文件分頁出現。它不會加入今日總覽，也不會在瀏覽器關閉時傳送通知。對租約通知期限、保單續約、學校文件或其他不能錯過的節點，建議同時在「任務與行事曆」新增一項有負責人與到期日的家庭任務。文件紀錄回答「原件在哪裡」，任務回答「誰要在何時做什麼」，兩者不能互相取代。

日期也不等於法律上的保存期限。稅務、保險、房屋、醫療或契約文件的留存要求會因文件目的與管轄地不同；App 不會自動刪除任何紀錄。應依原始機關、專業人士或契約要求判斷，再把複查理由寫清楚。

## 用關聯資產避免「同品牌、不同設備」的混淆

家中有三台相同品牌冷氣時，只寫「冷氣手冊」不夠。先在家庭資產建立「主臥冷氣」、「客廳冷氣」等可辨識名稱，再讓發票、保固條款、說明書位置與維修單各自連到正確資產。

目前關聯資產不會讓資產卡反向顯示完整文件清單，也不是可以點開的資料夾。它的價值在資料關係：文件卡會顯示資產名稱，JSON、CSV 與選擇包含文件的交接摘要會保存連結。資產封存後，舊文件仍留在資料庫；只是新增文件時不再把封存資產列入選單。

## 交接摘要只在你主動選擇時帶出文件位置

家庭交接設定檔的「包含文件位置」預設關閉。開啟後，摘要會列出文件名稱、分類、原始位置、關聯資產與複查日期；文件備註不會帶入。這不是自動判斷敏感性的功能，位置文字本身仍可能暴露「護照放在哪個櫃子」或「保險箱由誰保管」。

給旅遊代管者、臨時照顧者與家庭備援管理人時，應建立不同設定檔。對方只需知道寵物用藥說明放在哪裡，就不要同時提供房契、保單與身分文件位置。列印前從頭讀一次摘要，因為 App 不知道你輸入的名稱或位置是否敏感。

## JSON、加密 JSON 與原始文件是三個不同備份問題

完整 JSON 會包含文件索引與備註；加密 JSON 會在瀏覽器內以密碼保護這份匯出。兩者都不會讀取位置欄指向的 PDF、照片、Email 附件或紙本。原始文件仍需要自己的備份與復原方式。

數位發展部資通安全署的[重要資料備份指引](https://web.moda.gov.tw/ACS/press/news/press/19496)提醒備份副本與復原演練的重要性。對 FamilyBoard 而言，應分別驗證兩件事：一是 JSON 能在測試環境通過驗證與還原，二是索引所寫的每個重要位置仍能找到正確原件。只做到其中一項，都不算完整復原能力。

跨裝置也不是同步。從筆電匯出後在手機「取代還原」，只完成當次資料搬移；之後筆電新增的文件不會自己跑到手機。每次移轉前先決定哪一份是目前主版本，避免兩台裝置各自修改後互相覆蓋。

## 台灣家庭可以從這一筆開始驗收

選一份真正會在期限前使用的資料，例如「租屋火災保險 2026」：分類填保險，位置寫「家庭雲端／住宅／保險／2026-fire-policy.pdf，8 月 22 日核對」，複查日設在續約決策前，備註只寫「確認新年度版本與承辦窗口」，不要貼完整保單號碼。

儲存後確認卡片的到期狀態與排序；另建同日任務並指定負責人；建立一個只給家庭備援管理人的交接設定檔，先不包含文件，再切換為包含並比較摘要差異。最後匯出 JSON，確認下載檔存在，並請另一位家人依位置文字找到原件。這套驗收同時測到輸入、提醒邊界、分享範圍與復原責任。

## 目前功能邊界

FamilyBoard 不會上傳或預覽檔案、不會辨識文件內容、不會替你判斷保存期限、不會自動掃描雲端資料夾，也沒有 OCR、全文搜尋、權限群組或跨裝置同步。文件名稱和位置可被能開啟該瀏覽器設定檔的人看到；App 本身沒有額外 PIN。

本機索引比散落的記憶可靠，但不是文件保險箱。把敏感原件交給有權限、加密、版本與復原機制的儲存方式；在 FamilyBoard 只留下完成家庭工作所需的最低限度位置資訊。

## 常見問題

### FamilyBoard 可以上傳 PDF、照片或掃描檔嗎？

不可以。它只保存位置索引與相關欄位，原件仍由你自己保管。

### 複查日期到了，App 會主動通知嗎？

不會。卡片會顯示到期狀態並排序，但不進今日總覽，也不發通知；重要日期要另建任務。

### 文件位置一定要在家庭交接中分享嗎？

不一定。只有交接設定檔主動包含文件時才會出現，而且備註仍被排除。

### 文件索引換手機後會自動出現嗎？

不會。必須手動備份與還原，且原始檔案不會包含在 FamilyBoard 備份中。
