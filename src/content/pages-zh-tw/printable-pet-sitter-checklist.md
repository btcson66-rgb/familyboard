# 可列印寵物照護檢查表：讓照護者知道今天要做什麼、異常找誰

寵物交接的重點不是把所有資料交出去，而是讓照護者在固定時間找到餵食、飲水、活動、清潔、藥物、用品與聯絡順序。列印前先填寵物代號、照護期間、飼主確認日期和主要照護者；完整地址、門禁、帳號、付款、晶片號碼或病歷全文只放在必要且受控的位置。不同寵物的飲食、行為與醫療需求不能用一張通用模板代替飼主和獸醫確認。

## 交接首頁

- [ ] 寵物代號／稱呼：____________________
- [ ] 照護開始與結束日期：____________________
- [ ] 飼主和備援聯絡人的查找位置：____________________
- [ ] 照護者可進入的區域與不能接觸的物品：____________________
- [ ] 住家、社區或管理單位的必要聯絡角色：____________________
- [ ] 最後一次和飼主走讀的日期：____________________

交接時請讓照護者用自己的話重述餵食、散步、清潔與聯絡順序。若只能說「照平常」，代表欄位不夠清楚，應補上時間、份量、用品位置或例外情況。不要把門禁碼貼在這張公開紙上；可寫「依受控訊息取得」並另行確認。

## 每日照護欄位

- [ ] 餵食時間／已確認份量／剩餘狀況：____________________
- [ ] 飲水補充與觀察：____________________
- [ ] 散步、活動、休息或貓砂清潔：____________________
- [ ] 藥物名稱、已確認的時間與紀錄位置：____________________
- [ ] 異常行為、嘔吐、腹瀉、受傷或食慾變化的觀察：____________________
- [ ] 當日照護者、日期與交接備註：____________________

藥物與飲食只照飼主提供且已確認的指示，不自行加量、停藥或改變食物。若寵物拒食、持續嘔吐、呼吸困難、出血、疑似中毒或出現飼主事前指定的警訊，清單只能幫助找到聯絡資訊；照護者應依飼主、獸醫或所在地緊急服務的專業指示處理。

## 用品、環境與外出

- [ ] 食物、零食、飲水器、牽繩、外出籠與清潔用品位置。
- [ ] 備用用品的中性代號、數量與補充方式。
- [ ] 空調、窗戶、陽台、植物、其他動物或不能進入的區域提醒。
- [ ] 外出路線、天候限制與照護者可執行的活動範圍。
- [ ] 飼主允許的拍照、訊息回報與照片保存方式。

不要把「可以自己處理」寫成沒有界線的授權。若需要帶去獸醫、購買用品或進入受控區域，先寫誰可同意、費用如何處理以及原始文件在哪裡。完成照護後回收含地址、聯絡或醫療資訊的紙本，並把需要長期追蹤的用品、回診與保固記錄轉成私人 App 紀錄。

## 版本與隱私

照護期間若餵食、藥物、聯絡人或住所安排改變，新增版本並通知所有照護者；不要讓舊表格和新指示並存卻沒有生效日期。FamilyBoard 的資料保留在目前瀏覽器，不會替你聯絡獸醫或自動發送提醒。未來公開內容若有寵物用品推薦，會和主要照護清單分開、揭露 affiliate 關係且可忽略，不會插入私密 App 或生成紙本。

**下一步：** 和照護者一起填寫交接首頁，再使用[寵物照護指示產生器](/zh-tw/tools/pet-sitter-instruction-generator/)建立只含必要資訊的版本。

## 交接演練與每日回報

正式離開前，請照護者拿著這張表完成一次餵食、補水、清潔或散步演練。飼主只在最後核對，不要一路口頭補充未寫下的例外。若寵物有多個碗、藥盒或外出用品，為每一項寫中性位置與使用後的歸位方式；「在櫃子裡」不如「KITCHEN-SUPPLY-02，左側第二層」容易交接。照護者每日可記下時間、觀察和照片代號，照片本身依飼主約定保存，不必全部傳到群組。

發現異常時先保留事實：發生時間、持續多久、吃喝狀況、活動、可見傷口或行為變化，以及已通知誰。不要在表格寫出未經確認的診斷，也不要自行更改藥物或食物。若飼主無法聯絡，依預先寫好的備援順序尋求獸醫或所在地緊急服務；表格只能幫助找到聯絡流程，不能延誤需要立即處理的情況。

照護結束後由飼主和照護者一起簽上回收日期，確認剩餘食物、藥物、鑰匙、外出用品與紙本都已交還。若下一次照護安排不同，建立新版本而不是覆蓋舊指示；這樣才能知道某次餵食、回診或用品變更適用的期間，也能在需要時快速撤回過時資訊。
