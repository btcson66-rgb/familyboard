# 可列印季節家庭檢查表：讓季節提醒配合住家與設備

同一張「春季大掃除」清單不會適合所有家庭。住在公寓、透天、租屋或有庭院的家庭，需要關注的設備不同；台灣的梅雨、颱風、高溫與濕氣，也不一定按照教科書的四季切換。這張表提供一個可重複使用的框架：在一個季節開始前，找出即將進入高負載的系統；在上一個季節結束後，記錄異常、收納與下一步。

請在表頭寫下日期、地區天氣情況和這次檢查的範圍。若你的家庭用「梅雨前／颱風季前／冬季用暖氣前」比春夏秋冬更實用，就直接改寫標題。每格都可以填「不適用」；高品質的檢查表不是塞滿所有可能工作，而是讓真正相關的項目有清楚的負責人和後續。

## 一、即將進入高負載的系統

- [ ] 設備或系統名稱：____________________________
- [ ] 本季使用情境（高溫、潮濕、連續降雨、寒冷、假期等）：________________
- [ ] 需要查看的原廠手冊、租約或官方要求：____________________________
- [ ] 需要預約、清潔、補充或更換的項目：____________________________
- [ ] 負責人與完成日期：____________________________________________

可以從冷氣、除濕機、熱水器、抽水設備、車輛、庭院排水或節慶大量使用的廚房設備開始，但不要假設每個家庭都有這些東西。記錄的是「準備做什麼」和「依據哪個來源」，不是在紙上自行發明所有設備的保養週期。若原廠要求的日期和季節不同，以原廠或合格服務商的建議為準。

## 二、即將離開高負載的系統

- [ ] 本季使用時是否出現異音、異味、錯誤、漏水或效能變化？
- [ ] 是否依說明清潔、關閉、排水、收納或保護設備？
- [ ] 是否有零件、耗材、保固或服務紀錄需要保存？
- [ ] 未完成的維修是否已建立下一步、負責人和日期？

「收尾」不是把設備關掉就結束。把你確實觀察到的問題寫下來，下一季開始前才不必重新猜測。高處、帶電、瓦斯、屋頂和結構工作不要為了填表而自行操作；記下現象與照片位置，交由合格專業人員評估。

## 三、外部環境與住家周邊

- [ ] 從安全可及的位置查看排水、窗框、陽台、門鎖或遮雨處是否有明顯變化。
- [ ] 記下與本地豪雨、颱風、乾旱或高溫相關的可見問題：________________
- [ ] 庭院、公共區域或大樓管理事項是否需要通知管理方？
- [ ] 是否有必須由專業人員處理的檢查或維修？________________________

這一段只處理你有權限且能安全觀察的範圍。不要把網路文章的「每戶都該做」當成所在地法規，也不要把房屋外觀檢查當成結構安全認證。若租屋，先看租約和聯絡流程；若是大樓，公共管線與外牆可能由管理單位負責。

## 四、家庭運作與季節行程

- [ ] 本季用品、藥品、雨具、清潔用品或兒童／長者照顧物品是否需要補充？
- [ ] 旅行、返鄉、開學、長假或照顧交接是否需要一份低敏感度的說明？
- [ ] 下個季節前有哪些帳單、續約、保險或服務期限？
- [ ] 家人是否知道這次由誰負責、在哪裡找到說明和備品？

不要在公開交接表寫入不必要的電話、序號、付款或私人備註。只列出對方真的需要的地點、一般責任和下一個日期；敏感資訊留在私人記錄與安全備份。若要把季節交接交給親友或照顧者，先確認對方只看到必要範圍。

## 五、留下紀錄，下一季再調整

- [ ] 更新資產的狀態、位置或備註。
- [ ] 在保養歷史寫下日期、結果與服務商參照。
- [ ] 將報價、預約、零件等待或再檢查建立為 App 任務。
- [ ] 重要變更後建立一份可還原的備份。

完成後用三句話收尾：這季發現什麼、誰做了什麼、下次先看哪裡。FamilyBoard 的資產、保養和任務能保存這些結果，但它不會自動知道你的氣候、設備手冊或家庭行程。每季依實際使用與可靠來源調整，會比複製一份看似完整卻與住家無關的清單更安全。這份季節紀錄也能成為下一次家庭會議的共同起點。
