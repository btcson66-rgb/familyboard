# 保固管理 App 教學：把「應該還有保固」變成可以查證的資料

設備故障時才開始翻信箱、購物平台與抽屜，通常已經太晚。真正有用的保固紀錄至少要能回答：是哪一台設備、提供者是誰、書面期間何時開始與結束、收據和條款原檔在哪裡，以及到期前誰要採取什麼行動。

FamilyBoard 的「保固」分頁是一份本機索引，不是業者的保固查詢系統。它依你輸入的日期顯示狀態，保留文件位置線索，但不會讀取條款、判斷故障原因或保證申請成立。先理解這個邊界，才能把它當可靠的家庭紀錄，而不是錯誤的權益承諾。

## 為什麼一定要先建立家庭資產？

新增保固時，「資產」與「截止日期」都是必填。資產選單只列出尚未封存的項目，所以應先到「家庭資產」建立清楚名稱，例如「廚房冰箱」或「主臥除濕機」，不要只寫「家電 1」。

資產紀錄負責辨識設備的品牌、型號、序號、購買日與備註；保固紀錄負責保存提供者、書面起訖日、收據位置、條款位置與個別說明。把兩者拆開，可以避免換新設備後沿用舊保固，也能讓同一個品牌的多台家電不會混在一起。

目前資產卡沒有統一詳情頁，不能點開後同時看到所有保固、保養與文件。這些紀錄仍在各自分頁中，透過相同資產名稱辨識。建立資產名稱時越具體，跨分頁複查越不容易找錯。

## 新增一筆保固，每個欄位怎麼寫？

開啟[繁中 App](/zh-tw/app/)後進入「保固」，依書面資料填寫：

| 欄位 | 實用寫法 | 不應假設的事 |
|---|---|---|
| 資產 | 選已確認型號的「客廳冷氣」 | 相同品牌就是同一台設備 |
| 提供者 | 製造商、零售商或第三方方案名稱 | 提供者名稱等於一定承保 |
| 開始日期 | 依發票、安裝單或條款記載 | 一律從購買日自動起算 |
| 截止日期 | 依正式文件輸入，必填 | 口頭說「兩年」即可自行推算 |
| 收據位置或索引 | 信件主旨、日期、檔名或紙本格位 | FamilyBoard 已保存收據檔案 |
| 條款或手冊索引 | 文件名稱、版本、頁碼與存放處 | 一般網路文章就是你的契約條款 |
| 備註 | 登錄狀態、客服案件編號、待確認問題 | 密碼、完整信用卡號或證件資料 |

開始日期可留空，截止日期不能。若文件只有購買日與期間，先使用[保固到期計算器](/zh-tw/tools/warranty-expiration-calculator/)做日期草稿，再回到業者條款、發票或登錄結果確認；不要把計算器結果當成業者承認的效力日期。

## 截止日與已過期狀態怎麼判斷？

保固卡每次顯示時，都把截止日與目前瀏覽器的本機日期比較：

- 截止日在今天或未來：顯示「截止日＋日期」；
- 截止日早於今天：顯示「已過期」；
- 截止日正好是今天：當天不會提前變成已過期。

清單會把尚未過期的保固放在前面，並依最近截止日排序；已過期的紀錄排在後面，最近才過期的先出現。這能讓快到期項目較容易被看到，但不等於通知。只有打開 App 才會看到狀態與順序更新，瀏覽器關閉時不會傳推播、電子郵件或簡訊。

日期徽章也不等於實際保障判斷。是否涵蓋零件、人工、運送、耗材、外觀或特定故障，仍以你與提供者之間適用的書面條款和實際個案為準。需要理解台灣常見的保證書、法定權利與業者承諾差異，可閱讀有官方來源的[產品保固追蹤教學](/zh-tw/guides/how-to-track-product-warranties/)。

## 收據位置與條款索引不是檔案上傳

FamilyBoard 不會把收據 PDF、保證書照片或電子郵件附件存進保固紀錄。欄位只保存文字線索，因此「在雲端」或「在信箱」通常不夠。可以寫成：

- 「Gmail，寄件者 shop@example，主旨訂單成立，2026-03-18」；
- 「家庭雲端／家電／廚房冰箱／receipt-2026.pdf」；
- 「書房白色文件夾／家電／第 3 透明頁」；
- 「原廠保證書版本 2026-02，第 4–6 頁」。

位置字串要讓另一位家人在你不在場時也找得到，但不要直接貼雲端密碼、一次性驗證碼、完整卡號或身分證字號。原檔仍要放在你控制且有備份的儲存位置；FamilyBoard 的 JSON 備份只會保存這些文字索引，不會把外部檔案一起打包。

## 到期前要做事，另外建立家庭任務

保固功能沒有「提前幾天複查」欄位。若希望在截止前 30 天檢查設備、找齊文件或確認登錄狀態，應到「任務與行事曆」建立一筆真正可執行的工作，例如：

1. 責任寫「確認廚房冰箱保固文件與目前異常」；
2. 指定一位負責人，而不是只寫在備註中；
3. 到期日設定在保固截止日前足夠處理的日期；
4. 備註寫資產名稱、保固提供者與完成標準；
5. 若已取得服務時段，再建立行事曆事件保存開始、結束與地點。

任務會進入今日總覽的未完成責任清單，但 FamilyBoard 仍不會在 App 關閉時通知。不可錯過的期限要再同步到家庭平常確實會看的提醒管道。

## 一個從購買到送修的實作流程

假設新買一台洗衣機：

1. 拍下機身銘牌與保存發票原檔，但不要把照片上傳到 FamilyBoard；
2. 在家庭資產輸入清楚名稱、品牌、型號、序號與購買日；
3. 在保固分頁選同一資產，照書面資料填提供者與起訖日；
4. 收據索引記可搜尋的信件主旨或檔案路徑，條款索引記文件版本；
5. 若條款要求註冊，另建任務「完成產品登錄並保存確認信」；
6. 到期前建立複查任務，而不是期待保固頁自動提醒；
7. 維修發生時，在保養維護留下完成事件與服務結果，保固分頁則保留案件編號或條款線索。

兩條歷程會分別存在「保養維護」與「保固」分頁，不會在資產卡自動合併。跨頁查找時用同一個明確資產名稱，並以原始文件判斷保障內容。

## 封存、編輯與本機儲存限制

資產封存後，既有保固不會被刪除或隱藏；保固卡仍顯示，但該資產不再出現在新增保固的有效資產選單。這適合已出售或汰換、但仍需要保留歷史的設備。

目前保固卡沒有直接編輯、刪除或封存按鈕。需要批次校正時，可從設定使用家庭資料總表 CSV，但匯入前一定要先匯出完整 JSON、閱讀預覽並抽查關聯。CSV 是編輯格式，不是完整復原格式。

所有資料保存在目前瀏覽器，不會自動同步到其他裝置。若清除網站資料、使用無痕模式或更換手機，未備份的保固索引可能消失。英文與繁中 App 只在同一瀏覽器共用同一份本機資料。

## 常見問題

### 保固截止日當天會顯示已過期嗎？

不會。截止日從隔天才會顯示已過期；是否仍可主張權利要看適用書面資料與實際情況。

### 保固快到期時 FamilyBoard 會傳通知嗎？

不會。請另外建立有負責人與到期日的家庭任務，重要期限再搭配外部提醒。

### 可以把收據 PDF 或保證書照片直接上傳嗎？

不行。FamilyBoard 只保存可找回原檔的文字索引。

### 封存家電資產會刪除已建立的保固嗎？

不會。既有保固仍留在保固分頁，只是不再能用該封存資產建立新的關聯紀錄。
