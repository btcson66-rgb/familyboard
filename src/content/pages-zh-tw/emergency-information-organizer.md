# 家庭緊急聯絡人 App 教學：先讓資料找得到，再決定哪些可以交給別人

真正需要找聯絡人時，最常遇到的不是「完全沒有電話」，而是資料散在通訊錄、聊天紀錄、帳單、管理室公告與某位家人的腦中。水電、瓦斯、社區管理室、設備原廠、寵物照護、可信任鄰居與家庭成員可能各有不同用途；只做一張沒有分類的名單，壓力一來仍然找不到正確的人。

FamilyBoard 的「緊急聯絡」分頁把姓名或單位、分類、電話、電子郵件、操作備註與顯示範圍留在目前瀏覽器。它不需帳號、不會上傳到 FamilyBoard 伺服器，也不會驗證聯絡方式。敏感標記能控制家庭交接，但不是加密功能；這是使用前最重要的界線。

## 先分清楚「家庭成員」與「緊急聯絡人」

家庭成員是家中負責工作的人，可以被指定為任務、保養或訂閱的負責人。緊急聯絡人則是需要在特定情境聯繫的個人或服務，例如：

- 社區管理室或保全；
- 水電、冷氣、鎖匠或設備原廠客服；
- 可信任鄰居、房東或代管人；
- 寵物醫院、照護者或接送聯絡人；
- 家庭約定的緊急聯絡窗口。

兩份名單不會自動連結。把家人重複加入緊急聯絡人並不會讓任務指派更完整，反而可能留下兩份不同電話。先決定名單用途，再建立必要紀錄。

## 欄位怎麼填，壓力下才真的有用

在[繁中 App](/zh-tw/app/)進入「緊急聯絡」，表單預設分類為「家庭聯絡人」。建議填法如下：

| 欄位 | 建議內容 | 不建議內容 |
|---|---|---|
| 人員或服務單位 | 可立即辨識的姓名或正式單位 | 只有「師傅」、「客服」 |
| 分類 | 管理室、水電、設備原廠、鄰居、照護 | 每筆都用「其他」 |
| 電話 | 已由帳單、官方頁或本人確認的號碼 | 未知來源轉傳的號碼 |
| 電子郵件 | 確認可聯絡的地址 | 帳號密碼或驗證碼 |
| 操作備註 | 服務範圍、可聯絡時段、案件線索 | 完整病歷、證件號碼、門鎖密碼 |
| 顯示範圍 | 可分享或敏感 | 把敏感當成「只有我能看」 |

卡片會先依分類、再依名稱排列。電話與電子郵件有值時可直接點擊，分別交給裝置的電話或郵件程式；FamilyBoard 自己不會撥號或寄出訊息，也不會判斷格式正確是否代表真人仍在使用。

## 「可分享」與「敏感」究竟控制什麼？

新紀錄預設為可分享。改成敏感後，會發生兩件事：

1. 緊急聯絡卡片顯示「私密」而不是「可分享」；
2. 家庭交接摘要一定排除該聯絡人，即使目前設定檔選擇包含非敏感聯絡人。

它不會做以下事情：

- 不會在緊急聯絡分頁把內容遮住；
- 不會從完整 JSON 備份移除；
- 不會從家庭資料總表 CSV 移除；
- 不會為該筆聯絡人另外加密；
- 不會影響家庭看板，因為家庭看板原本就不顯示任何聯絡人。

因此，敏感標記適合表達「不要交給保母或代管者」，不適合表達「即使有人打開這台裝置也看不到」。如果備註內容不適合讓能使用瀏覽器的人讀到，就不應放在這裡。

## 一個交接前的雙層聯絡清單範例

假設家庭準備週末外出，家中由親友照顧寵物，可以建立：

- 「大樓管理室」，分類「社區」，電話已向正式公告確認，備註寫訪客與包裹處理方式，標記可分享；
- 「固定水電服務」，分類「居家維修」，備註寫服務範圍與平日聯絡時段，標記可分享；
- 「家庭私人醫療窗口」，分類「家庭」，備註只寫最低限度的聯絡目的，標記敏感。

接著建立「週末寵物照護」的家庭交接設定檔，選擇包含非敏感聯絡人。列印或另存前檢查摘要：管理室與水電可以出現，私人醫療窗口不會出現，而且聯絡人的操作備註本身也不會被交接摘要拉入。更完整的設定檔規則可看[家庭交接清單教學](/zh-tw/features/household-handoff/)。

## 可分享不等於適合公開

「可分享」只代表可以進入家庭交接，不代表適合放在公開網頁、社群貼文或無人看管的螢幕。電話號碼、住戶姓名與誰有備用鑰匙等資訊，仍應只交給有需要的人。

Family Display 不顯示任何聯絡人，所以不要期待把管理室電話放在廚房看板。若需要一張真正可放在冰箱或防災包的聯絡表，可使用[免費家庭緊急聯絡表產生器](/zh-tw/tools/emergency-contact-sheet-generator/)產生後自行審閱、列印；工具結果是否正確仍要由家庭逐項核對。

## 定期複查：電話能點，不代表現在有效

緊急聯絡分頁目前沒有複查日期、到期提醒或自動驗證。建議在家庭每季或半年複查時處理：

1. 從服務商正式帳單、官方頁面或本人確認號碼；
2. 實際檢查電子郵件拼字與電話國碼、區碼；
3. 移除已離職、搬家或不再提供服務的聯絡人；
4. 重看每筆敏感標記是否仍符合交接目的；
5. 更新紙本備援與 FamilyBoard 備份；
6. 重要官方緊急資訊以所在地最新官方來源為準。

若某個電話一定要在指定日期前確認，可以另外建立家庭任務並指派負責人。FamilyBoard 任務也不會主動推播，所以不可錯過的期限仍應搭配家人真正使用的提醒方式。

## 本機保存、完整備份與裝置故障風險

緊急聯絡資料存在目前瀏覽器的 IndexedDB。換手機、開無痕視窗、使用另一個瀏覽器或清除網站資料，都可能看不到原資料。FamilyBoard 沒有帳號端副本，無法替你找回未備份名單。

完整 JSON 備份會包含可分享與敏感聯絡人、電話、電子郵件和備註。一般 JSON 可直接讀取；加密 JSON 能保護備份檔案在未解密時的內容，但密碼遺失也可能讓檔案無法還原。CSV 適合批次檢查與校正，不是完整復原備份。詳細風險可閱讀[繁中資安說明](/zh-tw/security/)。

裝置在停電、損壞或沒電時可能無法使用，因此高重要性的聯絡方式應依家庭情境保留適當離線備援。FamilyBoard 是整理與交接工具，不是緊急通訊系統，也不能取代所在地官方指引。
