# FamilyBoard 清除本機家庭資料教學：確認備份後再重設

設定頁的「清除本機家庭資料」是 FamilyBoard 的破壞性操作。輸入畫面顯示的完整家庭名稱後，它會移除目前瀏覽器裡的所有 FamilyBoard 資料並重新載入。外部文件、附件和備份檔不會被刪除，也不會上傳到某處等你日後復原。沒有獨立副本時，這個動作無法靠 App 撤銷，所以它應該是資料生命週期決策，而不是日常整理。

## 先判斷是否真的需要清除

在裝置交給另一個家庭、退休瀏覽器設定檔，或準備用完整且已驗證的備份重建時，清除可能合理。它不是儲存健康警示、忘記密碼或 Service Worker 更新的修法。若資料庫打不開，App 會提醒不要清除瀏覽器資料；先保留備份，改用支援的設定檔再試。如果看板顯示舊任務，也應先比較來源和備份，而不是直接刪掉本機狀態。

## 清除前完成六項檢查

1. 從目前家庭匯出明文或加密 JSON。
2. 把檔案放到瀏覽器之外、權限受控的可靠位置。
3. 用唯讀還原驗證架構、匯出時間和紀錄總數。
4. 依受控計畫測試開啟備份，不要在共用畫面猜密碼。
5. 記下誰批准清除、原因和清除後的下一步。
6. 確認外部附件與文件來源各自有可用副本。

App 不會為清除動作自動下載安全快照；下載但沒有檢查的檔案不能證明可以復原。若要搬到新瀏覽器，盡量先在新設定檔完成首次還原並抽查，再清除舊設定檔。

## 確認精確的家庭邊界

只有當輸入文字完全符合家庭名稱時，按鈕才會啟用。先讀出家庭名稱和瀏覽器設定檔，再仔細輸入。這個摩擦不能阻止刻意清除的人，卻能降低瀏覽設定時誤按的機會。不要為了增加難度把秘密當成家庭名稱；名稱可能出現在 App 和備份裡。

## 清除後也要複查

頁面會回到首次啟動畫面。若清除是裝置交接的一部分，不要立刻建立新的家庭；先確認舊 JSON 和批准紀錄都保留。若目的是隱私，還要另外檢查瀏覽器下載、保存的設定檔和外部來源權限，因為清除 FamilyBoard 不能撤回別人已經複製的 CSV 或截圖。

未來若出現儲存硬碟、防窺工具或密碼管理器的聯盟窗格，會清楚揭露並可跳過。商品不能撤銷清除，也不能保證所有瀏覽器副本都消失。免費 App 的安全規則就是：匯出、驗證、取得同意，再只清除預定的本機設定檔。清除後若重新還原，應把新匯出日期和抽查結果寫回交接紀錄，讓資料歷史有清楚起點。

如果清除是為了交給下一位家庭角色，先把復原檔與交接說明交給對方，再確認對方能在自己的設定檔完成驗證。若只是想重新整理資料，應優先使用資料留存決策、逐筆修正或建立新的安全快照，不要用整庫清除代替分類。清除後仍可能留有下載檔、試算表副本、截圖或外部來源權限，這些需要依各自的保存和撤回規則處理，不能宣稱一次按鈕就完成所有隱私要求。

按下按鈕前可由兩個角色交叉確認：「這是正確的瀏覽器嗎？」「JSON 真的能讀嗎？」「外部檔案是否另有副本？」「清除後誰負責重新建立？」把答案寫下來，才能讓破壞性動作有可追溯的理由。若其中一題沒有答案，就先停下來保存現況。

清除完成後不要把重新出現的啟動畫面誤認為資料已安全銷毀；它只代表目前資料庫空了。仍要依瀏覽器、下載資料夾和外部來源的規則逐一檢查，並把新設定檔的首次匯出日期記錄下來。

如果清除後發現備份無法開啟，先停止建立新資料，保留錯誤訊息與原始檔，改從另一份受控副本尋找復原路徑。

只有在來源、副本、授權和下一步都清楚時才執行；任何一項仍待確認，就先保留本機資料並回到備份檢查。

**情境 CTA：** 匯出並驗證 JSON，寫下清除原因，確認設定檔和家庭名稱，復原路徑準備好後才清除。
