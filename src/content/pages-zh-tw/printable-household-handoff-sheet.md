# 可列印家庭交接表：讓責任換手，而不是把一堆資料丟給下一個人

出差、住院、照顧家人、搬家或家庭角色更換時，最常見的問題不是家裡完全沒有資料，而是接手人不知道「這一週要先做什麼、做到哪裡算完成、可以看哪些資料、什麼時候不再需要權限」。這份紙本交接表把範圍縮到一個人、一段期間和一組明確工作。它是溝通與複查工具，不是授權書、契約、緊急服務替代品，也不是把家庭完整資料庫複製出去的方法。

## 先寫交接範圍與有效期間

**交接目的：** □短期代班　□旅行　□照護備援　□搬家　□正式角色移交　□其他：________

**生效日期：** __________　**到期／複查日期：** __________　**準備人：** __________

**接手角色：** __________　**本表不處理的範圍：** ______________________________

短期代班和正式角色移交不能共用模糊的「直到需要為止」。寫出開始與結束日期，讓接手人、原負責人和其他家人知道何時再檢查。到期日不是自動刪除資料的按鈕，而是逐項確認工作、收回臨時權限、刪除不再需要的副本或重新產生新版本的控制點。若範圍變更，保留舊版本並註明新版本生效日，不要在一張已經流通的紙上悄悄改內容。

一列只放一個能驗收的工作。「處理帳單」太寬，改成「核對某筆已授權帳單的到期日，將日期與單據位置回報給家庭協調人」；「照顧房子」也應拆成檢查、聯絡、回報等不同責任。付款、取消、續約、服務預約與租屋通知要寫清楚實際來源，不要把猜測的期限當成正式通知。遇到立即危險，先離開並使用所在地官方緊急服務、管理單位或合格專業協助，不要等待紙本表格。

| | | | □是 □否 |

把「誰做」和「誰負責發現該做」分開寫。例如垃圾回收不只是把袋子拿出去，還包含查看所在地公告、準備分類物與在變更時通知家人；家電保養也不等於任何人都能拆機。若工作涉及瓦斯、電氣、屋頂、結構、污染水、醫療、法律或金融判斷，接手人只能負責找到適當來源和聯絡，不要把專業工作偽裝成家庭勾選項目。

## 目前住家問題與來源

**問題／觀察：** __________________________________________________________

**相關房間或物品代號：** __________________　**首次觀察日期：** __________

**已聯絡的角色／來源：** _________________________________________________

**下一步、期限與負責人：** _______________________________________________

只記錄可觀察事實和可靠來源，例如「洗衣機右側地面於 8/29 18:10 可見水痕，照片 ITEM-02，已通知房東」。不要把「一定是排水泵壞了」或「保險一定會賠」寫成結論。服務商、房東、管委會、公用事業或保險公司的回覆要保留原始位置和日期；交接表只放接手人完成工作所需的最小索引。

## 寵物、家人與日常支持

**照護對象／代號：** __________________　**日常節奏與觀察：** __________________

**已同意的照護方式與聯絡來源：** _________________________________________

**例外時要通知誰：** _____________________________________________________

照護資訊可能涉及健康、學校、行程或隱私。只記錄這段期間和這項照護真正需要的內容；醫療指示、處方、完整身分資料與正式紀錄應回到授權來源，不要用家庭紙本自行改寫。若對象有立即危險或需要專業判斷，依所在地緊急服務與合格專業指示處理，交接表不能取代照護計畫。

|---|---|---|---|---|
| 住宅／管理 | | | | |
| 設備／服務 | | | | |
| 家庭支持 | | | | |

不要只貼一串電話。接手人需要知道這個來源負責什麼、哪一天核對過、什麼情況才能使用。電話、電子郵件、服務入口和社區公告可能改變，交接前應再確認。真正的緊急聯絡應以所在地官方資訊為準；普通家庭聯絡人不能代替消防、救護、警察或公用事業的現行指示。

## 明確納入與明確排除

**本次明確納入：** ______________________________________________________

**本次明確排除：** ______________________________________________________

納入可以是近期任務、某筆已授權帳單的日期、住宅服務聯絡和一份完成證據的位置；排除則要明寫密碼、驗證碼、門禁碼、完整金融資料、完整身分證件、與本次無關的醫療／法律資料及其他私人紀錄不在授權範圍。只寫「相關資料」會讓接手人猜測，也會讓建立者誤以為對方已看到整個家庭資料庫。

紙本、下載檔和聊天照片都可能被轉傳。不要把秘密藏在「備註」欄，也不要因為接手人是家人就跳過最小揭露。必要的帳號或設備存取應使用獨立、可撤回且有權限控管的方法；表上最多留下受保護位置的索引。交接期滿要確認臨時權限收回、紙本回收、下載檔刪除或仍有保存必要。

## 用一次小測試驗收交接

把表交給接手人，請他在不靠建立者口頭提示的情況下完成三件事：找到一個未來 30 天期限、指出一個合法且用途正確的聯絡來源、說出一項工作的完成證據。若對方只能說「我會再問你」，就把觸發、角色、來源或證據寫得更清楚，並記下修正日期。演練不要為了測試而延遲付款、關閉服務、操作高風險設備或分享正式密碼。

**測試日期：** __________　**測試人：** __________　**找不到的項目與修正：** __________________________

## 到期、延長與正式移交

到期時把每一列分成已完成、要轉回原負責人、需要延長並重新確認三類。核對付款或服務結果、回收鑰匙與設備、撤除臨時存取、刪除不再需要的副本；仍有價值的事件回寫 FamilyBoard 或家庭正式紀錄，不能只留在過期紙本。若要延長，重新填寫範圍和日期，不要讓一張表永久漂流。

正式角色移交還要確認新負責人能獨立找到文件、理解未結事項、使用自己的正式權限，以及在備份還原測試中取得需要的資料。原負責人的私人帳號不應成為家庭服務唯一入口，也不要因為「大家都知道密碼」就跳過服務方的授權流程。

## 和 FamilyBoard App 搭配

紙本適合走動複查、短期代班和家庭會議；若需要從現有紀錄挑出未來工作，可使用 [家庭交接摘要產生器](/zh-tw/tools/home-handoff-summary-generator/)。產生器只處理你這次輸入的文字，不會自動讀取 App 任務、聯絡人、文件或授權任何人；真正長期的責任、事件和備份仍要由家庭手動確認。核心資料留在目前瀏覽器，紙本也不是備份，請依自己的流程保存、測試與回收。

**下一步：** 選一位接手角色、一個到期日和三項低風險工作，完成查找測試後再決定是否擴充範圍。好的交接不是給出去最多資料，而是讓下一個人知道現在能做什麼、不能做什麼，以及何時必須重新確認。
