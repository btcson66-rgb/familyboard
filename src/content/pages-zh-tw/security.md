# FamilyBoard 資安說明：本機優先減少資料集中，但不等於沒有風險

FamilyBoard 不會宣稱任何網頁應用程式「無法被破解」或「百分之百安全」。目前的設計重點是：核心家庭紀錄留在使用者自己的瀏覽器、不要建立集中保存每個家庭資料的帳號資料庫、公開說明備份格式與限制，並把公開網站、私密 App、列印內容和第三方連結分開。

這個架構降低了一類風險，卻不會取代裝置鎖定、瀏覽器更新、備份管理與分享前檢查。以下內容描述的是 2026 年 8 月 22 日複查時的實際程式行為。

## 家庭紀錄放在哪裡？

你在 `/app/` 或 `/zh-tw/app/` 建立的家庭、成員、設備、保養、保固、訂閱、任務、緊急聯絡人、文件索引與交接設定，主要寫入目前瀏覽器設定檔的 IndexedDB。FamilyBoard 沒有接收這些紀錄的登入系統、家庭雲端資料庫或同步 API。

公開計算器與產生器也在目前頁面內計算。按下「儲存到 App」時，結果只會先寫入相同網站來源的 `localStorage` 工具收件匣，再由同一個瀏覽器中的 App 匯入；它不會因此傳到 FamilyBoard 伺服器。公開網站的分析事件只允許工具代號或聯盟商品類別，不會把姓名、電話、日期、金額或自訂文字放進事件參數。

## 本機優先能保護什麼，又不能保護什麼？

沒有集中式家庭資料庫，代表 FamilyBoard 營運者不會持有一份可以一次洩漏大量家庭紀錄的伺服器副本，也無法查看你輸入的內容。但資料仍存在裝置上；若其他人能解鎖裝置與瀏覽器設定檔、惡意程式或擴充功能取得網頁資料權限，或你把可讀備份放在公開位置，本機資料仍可能被看到。

FamilyBoard App 自己沒有額外的 PIN、帳號登出或多人權限系統。共用電腦時，應使用獨立且有密碼的作業系統帳號或瀏覽器設定檔；處理聯絡方式、序號、文件位置或家庭行程後，離開裝置前要鎖定螢幕。無痕模式也不適合保存長期紀錄。

## 一般 JSON、加密 JSON 與 CSV 的差別

一般 JSON 是完整且容易移轉的備份，但文字內容可直接被讀取。家庭資料總表 CSV 同樣是明文，而且可能集中呈現多個資料表的內容；它適合試算表檢查與批次編輯，不是用來公開分享的表單，也不是完整災難復原格式。

加密 JSON 會在瀏覽器內使用 Web Crypto API。現行檔案格式從你提供的密碼以 **PBKDF2-SHA-256、310,000 次迭代**衍生 256 位元金鑰，再以 **AES-256-GCM** 加密；格式版本與必要中繼資料會一併接受驗證，讓被竄改或密碼錯誤的檔案無法靜默匯入。每次匯出會使用新的隨機 salt 與初始化向量。

加密只保護備份檔案在沒有密碼時不易被直接讀取。它不能修復已被入侵的裝置、不能阻止弱密碼被猜中，也不能讓損壞或忘記密碼的檔案自動復原。FamilyBoard 不會收到密碼，沒有復原金鑰，也沒有客服可以替你重設。

## 一套更可靠的備份做法

1. 完成第一批重要資料後，匯出一份完整 JSON，確認下載檔案確實存在。
2. 若備份會離開受信任裝置，改用一組獨特且足夠長的密碼匯出加密 JSON。
3. 把至少一份備份放在不同於原裝置、且由你控制的安全位置；不要只留在「下載」資料夾。
4. 用測試資料或另一個瀏覽器設定檔定期驗證檔案能通過預覽與還原，不要等到裝置故障才第一次測試。
5. 每次大量匯入或清除網站資料前重新匯出，並刪除已不需要、含敏感內容的舊明文副本。

App 可以向瀏覽器要求持久儲存，但是否核准由瀏覽器決定。即使顯示已核准，也不是備份保證；清除網站資料、移除瀏覽器設定檔、裝置損壞或使用者手動刪除，仍可能讓紀錄消失。

## 家庭展示、交接與列印前仍要人工確認

展示模式和交接摘要會刻意縮小資訊範圍，不把完整 App 當成公開看板；但每個家庭對「可以讓誰看到」的界線不同。交給保母、照護者、房屋管理人或訪客前，必須逐項檢查姓名、電話、住址、行程、文件位置與備註是否真的需要出現。

列印或下載後的檔案已離開 App 的控制範圍。請確認印表機、共用資料夾、通訊軟體與回收方式符合資料敏感度；過期的緊急聯絡表也應更新或銷毀，避免在真正需要時使用錯誤資訊。

## 更新與供應鏈界線

FamilyBoard 會透過一般網站部署更新 App 外殼與程式碼。Service Worker 可能暫時保留已快取版本；App 提示有新版本時，應先完成備份，再套用更新。作業系統、瀏覽器與必要擴充功能也應保持在仍受支援的版本，並移除不需要或來源不明的擴充功能。

公開原始碼與自動測試有助於檢查，但不能證明不存在漏洞。安全說明只描述已實作的防線，不會把一次測試結果包裝成永久保證。

## 如何私人回報漏洞

若發現惡意程式注入、資料邊界繞過、備份驗證缺陷、供應鏈風險或其他可被利用的問題，請使用 [GitHub 私人漏洞回報](https://github.com/btcson66-rgb/familyboard/security/advisories/new)。請提供受影響版本、最小重現步驟、影響範圍與你已確認的條件，但不要測試不屬於你的資料、帳號或裝置。

一般功能錯誤可以走[繁中聯絡頁](/zh-tw/contact/)的公開 issue；漏洞細節、備份檔、存取權杖與家庭資料不可貼在公開 issue。FamilyBoard 目前沒有公開的懸賞或獎金計畫，因此不承諾付款，也不要求你先公開證明問題。

## 常見問題

### FamilyBoard 把家庭資料存在本機，就代表百分之百安全嗎？

不代表。本機優先能減少集中式伺服器外洩面，但能解鎖裝置與瀏覽器設定檔的人仍可能看到資料；惡意擴充功能、裝置失竊、未更新的系統與不安全備份也都是風險。

### FamilyBoard 的加密備份使用什麼方法？

加密匯出在瀏覽器內使用 Web Crypto API，以 PBKDF2-SHA-256 和 310,000 次迭代從密碼衍生金鑰，再用 AES-256-GCM 加密及驗證檔案。FamilyBoard 不會收到或保管密碼。

### 忘記加密備份密碼可以重設嗎？

不可以。FamilyBoard 沒有帳號、雲端金鑰或密碼代管服務；忘記密碼時，營運者無法替你解開檔案。匯出後應立即用另一個瀏覽器設定檔或測試資料驗證還原流程。

### 發現可能的安全漏洞要貼到公開 issue 嗎？

不要。請使用 GitHub Security Advisories 的私人漏洞回報入口，避免公開可被利用的步驟、家庭資料、備份檔、存取權杖或其他敏感內容。
