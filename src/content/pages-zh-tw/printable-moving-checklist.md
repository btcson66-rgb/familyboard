# 可列印搬家檢查表：把前後兩個住家的責任交接在同一條時間線上

搬家最容易遺漏的不是紙箱數量，而是「誰在什麼日期確認了哪份來源」。水電網路開停、租約或交屋、屋況照片、重要文件、箱件位置和第一晚用品各有不同負責人。這張表先建立時間線，再讓你刪掉不適用項目；它不是搬家公司、房東、社區或政府的正式流程，也不會替你判定損害責任或契約期限。

## 搬家前兩到六週

- [ ] 寫下搬家、交屋或租約生效日期，標註來源文件與時區。
- [ ] 確認搬運、電梯、停車、管理室與進出時段的聯絡角色。
- [ ] 設定水、電、瓦斯、網路或其他服務的停止／開始申請與確認編號位置。
- [ ] 建立箱件代號：房間、箱號、優先順序；重要文件不要混入一般箱。
- [ ] 匯出 FamilyBoard 或其他家庭紀錄的備份，並在另一台裝置確認檔案可讀。
- [ ] 先整理第一晚用品、藥品、寵物用品、充電器、清潔用品與換洗衣物。

不要只把「已申請」當成「已生效」。每個服務都拆成申請日、業者確認、實際切換與現場結果。若時間受到房東、管理單位或搬運方影響，把等待中的回覆列給具體負責人，避免所有人以為別人會追蹤。

## 舊屋最後走讀

- [ ] 依房間拍攝可見屋況與固定設備，記下檔案代號和拍攝日期。
- [ ] 記錄水電表或設備讀值的來源與時間，不自行拆卸或操作危險設備。
- [ ] 確認鑰匙、門禁、遙控器、信箱與停車物品的交還方式。
- [ ] 檢查是否留下包裹、文件、藥品、冰箱食品或需要交接的寵物植物安排。
- [ ] 將清潔、修繕、抄表或押金相關事項分別記錄，附上通知與回覆位置。

走讀只寫看得到的事實，例如「浴室門框下方有水痕，照片 MOVE-08，已通知管理室」。不要在紙上寫「房東一定要賠」或「這是管線問題」這類未查證結論。涉及電氣、瓦斯、結構、黴菌或高處工作時，停止自行處理並找適當協助。

## 新屋第一天與第一週

- [ ] 確認進屋權限、鑰匙數量、管理規則與緊急聯絡來源。
- [ ] 以房間和箱號確認最重要的文件、床品、飲水、照明與充電物品。
- [ ] 記錄新屋可見屋況、固定設備型號、說明書與保固位置。
- [ ] 確認水、電、瓦斯、網路或設備服務實際可用；異常只記錄觀察並通知負責人。
- [ ] 將未完成的交屋、修繕、退款、地址變更或收件問題建立成有日期的任務。

完成後把需要長期追蹤的資產、保養和文件位置放入[繁中 App](/zh-tw/app/)，紙本保留為短期交接證據。若分享給搬運方、房東、家人或管理員，只提供對方需要的最低資訊，移除完整住址、門禁、帳號和付款資料。

## 版本、備份與推薦界線

搬家日期變更、服務商改期、箱件遺失或屋況有新發現時，新增版本並標記舊版，不要擦掉原始走讀。未來公開頁若有收納箱、標籤或搬家用品推薦，會位於清單之外並清楚揭露 affiliate 關係；不會出現在私密 App、生成結果或列印內容中。

**下一步：** 先填入搬家日期、交屋責任與三個第一晚用品，再開啟[搬家整理指南](/zh-tw/guides/moving-house-organizer/)安排後續。

## 箱件與責任交接

每個箱件只需要一個容易讀的代號，例如 `K-03` 代表廚房第三箱；紙本記錄房間、箱號、優先順序、是否含重要文件和開箱後的實際結果。不要在外箱或共用表格寫帳號、付款、完整地址或身分資料。搬運者、家人和管理員看到的欄位可以不同，交接時先說明哪些項目只是待確認，不要把「已搬入」誤寫成「已驗收」。

第一晚結束後，用十分鐘複查三件事：重要文件是否找得到、基本水電與照明是否能安全使用、仍等待誰的回覆。把未完成項目分成舊屋、新屋、公共服務和文件四類，各自寫負責人與日期。若屋況或箱件有爭議，保留照片、通知、回覆和版本，不要刪掉原始觀察。搬家完成不等於所有契約、押金、保固或地址變更都已結束，這些要依各自來源繼續追蹤。

搬家後一週再列印一頁「尚未完成」複查單，確認哪些服務已實際切換、哪些文件已放到受控位置、哪些設備需要手冊或保養資料。若家庭使用 App，先匯入中性代號與日期，再把紙本放在不會被訪客取得的位置；完成保存後回收含敏感資料的草稿。
