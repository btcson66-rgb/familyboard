# FamilyBoard 儲存健康警示教學：讀懂用量、配額與備份日期

FamilyBoard 是 local-first App，家庭資料放在目前開啟它的瀏覽器。儲存健康卡片同時顯示四種容易混淆的訊號：估算已使用位元組、瀏覽器管理的可用配額、是否獲得持久儲存，以及上一次成功匯出 JSON 的年齡。這些數字只是在描述風險，不能證明備份存在，也不能代表雲端容量。看到警示時應先做受控的可攜式副本，不要把警示當成清除資料的理由。

## 用量和配額是兩個問題

「已使用儲存」是瀏覽器估算這個網站所占的空間；「配額」是瀏覽器當下分配給這個來源的容量，有些瀏覽器只會顯示瀏覽器管理的配額。它們都不是家庭紀錄筆數，也不是雲端備份額度。資料很少仍然可能非常重要，而配額很大也無法防止裝置遺失、瀏覽器設定檔被刪除、無痕模式結束或儲存政策改變。把數字當成早期訊號，並另外保留可攜式匯出檔。

## 持久儲存是保護，不是備份

卡片會顯示「已授予」或「此瀏覽器未保證」的持久儲存狀態。未保證時，FamilyBoard 提供「要求耐久儲存」按鈕，透過瀏覽器的 `navigator.storage.persist()` 提出要求。瀏覽器可能根據使用情形、權限政策、裝置空間和自己的規則同意或拒絕。即使顯示已授予，也不能找回被偷的裝置、刪除的設定檔或從未匯出的資料。適合的話可以安裝 PWA、保持瀏覽器更新，並繼續固定匯出 JSON。

## 七天備份警示代表什麼

FamilyBoard 會記錄最近一次成功匯出 JSON 的時間。若從未成功匯出，卡片會提醒「在加入不可取代的紀錄前先匯出 JSON」；若距離上次匯出至少七天，則顯示檔案已經幾天沒有更新，請建立新副本。App 不知道哪些資料對你最重要，也不知道下載後檔案是否真的放在另一個可靠位置，所以採用簡單而保守的門檻。明文 JSON 方便攜帶；不希望檔案內容直接可讀時，可以使用加密匯出，但密碼必須另行保存，遺失密碼無法由 App 找回。

## 看到警示時的安全順序

1. 暫停輸入重要的新資料，先確認正在處理的是哪一個瀏覽器。
2. 從「匯出備份」卡片匯出 JSON，確認下載確實完成。
3. 將檔案放到瀏覽器之外、權限受控且能長期保存的位置。
4. 使用「不還原只驗證」檢查匯出時間、架構版本和紀錄總數。
5. 若尚未保證持久儲存，可以提出一次要求並記下瀏覽器回應。
6. 設定下一次複查日期；不要用清除網站資料當作整理步驟。

## 這張卡片看不到的事情

它不能檢查外接硬碟是否健康，不能證明搬移後的備份檔沒有損壞，也不知道另一台裝置的資料庫內容。若要在隔離的瀏覽器測試還原，請先準備來源檔、安全快照和明確目的。帳密、完整帳單與私人對話仍應留在受控來源；FamilyBoard 是本機家庭紀錄工具，不是遠端檔案庫。

也要留意「用量沒有增加」不代表匯出成功，因為下載檔案通常不會回寫本機資料庫；「持久儲存已授予」也不代表檔案已放到第二個地點。家庭可以每月安排一次小型演練：由一位角色讀出備份位置，另一位角色在不修改正式資料的情況下驗證檔案，第三位角色確認誰負責下一次匯出。若裝置空間不足、瀏覽器政策改變或使用者即將換機，應提早匯出，不要等到警示變成資料遺失才處理。

把演練結果寫下來，包括驗證日期、檔案大小、紀錄總數和仍待改善的保存位置。這些是家庭自己的觀察，不是瀏覽器承諾；來源改變時也要重新檢查。

日後文章旁可能出現儲存媒體、標籤或備份資料夾的聯盟商品窗格，會清楚揭露且可以跳過。商品不會授予持久儲存，也不能取代免費的 JSON 匯出與驗證流程。真正可靠的做法是讀懂四項訊號、建立副本、驗證副本，再讓家庭知道副本放在哪裡。

**情境 CTA：** 讀完四項儲存訊號後匯出新的 JSON、完成唯讀驗證，並記下可靠副本的保存位置。
