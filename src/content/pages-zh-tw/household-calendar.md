# 家庭行事曆 App 教學：把到府服務與家庭時段放在真正需要的位置

家庭行事曆不一定要取代手機原本的日曆。對多數家庭來說，私人約會、工作會議與孩子課程已經有固定工具；真正容易漏掉的是「跟家中設備或交接有關、但不是每個人私人行程」的時段，例如冷氣清洗、瓦斯檢查、社區水塔清洗、家具配送、維修人員到府或保母接手時間。

FamilyBoard 的行事曆位在「任務」分頁，目的就是把這類家庭事件放在責任與居家紀錄旁邊。它免費、不需帳號，也不讀取你原本的日曆；相對地，它不會同步、推播或替你處理重複事件。先理解這個界線，才不會把它誤用成雲端家庭日曆。

## 先判斷：這是一個事件，還是一項任務？

兩者最簡單的判斷方式，是問「需要知道何時發生，還是需要知道誰必須完成？」

| 情境 | 建議類型 | 原因 |
|---|---|---|
| 冷氣師傅 8 月 28 日 14:00 到府 | 行事曆事件 | 有明確開始時間與可能的結束時間 |
| 8 月 27 日前確認師傅與停車方式 | 家庭任務 | 有負責人、期限與完成狀態 |
| 每週三倒資源回收 | 家庭任務 | 重點是誰做完，不是佔用一段時段 |
| 搬家公司 09:00 至 13:00 搬運 | 行事曆事件 | 家庭需要保留一段共同時段 |
| 搬家前完成冰箱除霜 | 家庭任務 | 完成與否比開始時間重要 |

實際上，同一件事常需要兩筆紀錄。到府維修是事件；「前一天移開家具並致電確認」則是任務。FamilyBoard 不會自動把兩者連起來，所以標題要能讓家人看懂彼此關係，例如「冷氣清洗到府」與「冷氣清洗前清空陽台」。

## 繁中事件表單每個欄位怎麼填

在[繁中 App](/zh-tw/app/)開啟「任務」，第二個表單就是「新增行事曆事件」。欄位不多，但每一項有不同的曝光範圍：

| 欄位 | 建議寫法 | 會不會出現在家庭看板 |
|---|---|---|
| 事件名稱 | 一眼能辨識、但不含敏感資料的短標題 | 會 |
| 開始日期 | 服務或交接真正開始的日期與時間 | 會顯示時間 |
| 截止日期 | 預估結束時間；跨日事件務必填寫 | 不會直接顯示 |
| 位置 | 「家中」、「管理室」或可信的簡短指示 | 不會 |
| 備註 | 聯絡方式、準備事項與進門流程 | 不會 |

開始時間為必填。若填結束時間，系統會要求它晚於開始時間；相同時間或較早的結束時間不會儲存，畫面會提示「結束時間必須晚於開始時間」。這項檢查避免輸入顛倒，但不會判斷服務商是否準時，也不會替你估計工時。

## 事件清單與「今天」的規則

任務分頁中的事件卡會依開始時間由早到晚排列，卡片顯示開始時間、位置、可選的結束時間與備註。事件沒有負責人、完成按鈕、封存或自動重複；目前快速介面也沒有單筆編輯與刪除按鈕。需要大量校正時，可使用設定頁的家庭資料總表 CSV，但修改前應先匯出完整 JSON 備份。

「今日總覽」不直接列出事件；[家庭看板](/zh-tw/features/family-display-mode/)才會顯示今天最多六筆事件。判斷規則如下：

1. 今天開始的事件會顯示；
2. 昨天或更早開始、但有結束時間且今天仍在期間內，也會顯示；
3. 昨天開始卻沒有結束時間的事件，不會永久留在今天；
4. 多筆事件依開始時間排列，只顯示前六筆；
5. 看板只顯示標題與開始時間，不顯示位置與備註。

例如「住家電梯保養」從 23:30 到隔日 01:00，兩天的看板都能看到。若只填開始時間，則只有開始當日會顯示。這是簡易家庭事件規則，不是具有時區、受邀者與全天事件設定的完整日曆系統。

## 一個台灣家庭到府維修的完整範例

假設冷氣原廠安排 8 月 28 日 14:00 至 16:00 到府保養，可以這樣拆：

1. 事件名稱填「客廳冷氣原廠保養」；
2. 開始與截止日期填服務窗口；
3. 位置填「家中，先至管理室換證」；
4. 備註填客服案件編號、進門前要聯絡哪位成員，以及「寵物先移到房間」；
5. 另外建立一筆 8 月 27 日到期、指定負責人的任務「確認冷氣保養與清空陽台」；
6. 保養完成後，到設備的保養維護紀錄按完成，留下真正做過的日期。

這三筆資料回答不同問題：事件回答何時到府，任務回答誰要準備，保養紀錄回答工作是否真正完成。不要把客服案件編號或門鎖資訊塞進事件名稱，因為名稱可能出現在共用看板。

## 重複事件與提醒的限制

FamilyBoard 事件沒有每週、每月或每年重複規則，也沒有瀏覽器推播、電子郵件或手機鬧鐘。家庭任務雖有「重複週期備註」，但「每週」只是給人看的文字；按完成不會自動算下個星期，也不會重開任務。

不能錯過的時間仍應放進家庭真正會查看的日曆或提醒工具。FamilyBoard 可以保存與居家設備、責任和交接相關的脈絡，但不應成為唯一的緊急提醒來源。每週整理時，可以依[家庭任務管理教學](/zh-tw/features/family-task-manager/)把已完成的重複工作手動建立下一筆。

## 跨裝置不是同步：舊平板要另外維護

英文與繁中 App 在同一個瀏覽器設定檔中會讀到同一份資料；同一瀏覽器設定檔的另一個分頁，也能在重新整理資料後看到更新。但手機與牆上平板是兩個不同的本機資料庫，即使使用相同品牌瀏覽器或相同作業系統帳號，也不會由 FamilyBoard 自動同步。

若要讓舊平板當家庭看板，可以選擇在平板上直接維護紀錄，或定期把確認過的完整備份移轉並還原。合併與取代會產生不同結果，操作前先保存兩端備份，避免把新紀錄覆蓋掉。不要因為畫面寫「每分鐘重新整理」，就以為它會從手機抓資料；那個計時器只重讀目前裝置的本機資料庫。

## 備份與敏感資料原則

事件的備註與位置會進入完整 JSON 備份與家庭資料總表。它們不會出現在公開 SEO 頁面，也不會被 App 分析追蹤，但任何能使用這個瀏覽器的人仍可能讀到。建議只保存完成家庭運作所需的最低資訊，密碼、門鎖完整密碼、醫療細節與證件資料另用適合的安全工具管理。

新增重要事件後，匯出一份可驗證的完整備份；需要保護檔案時使用加密 JSON，並把密碼放在不同的安全位置。家庭資料總表適合批次檢查，不是完整復原備份。
