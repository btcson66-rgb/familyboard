# FamilyBoard PWA 更新教學：重新載入但不清除本機資料

FamilyBoard 使用瀏覽器 Service Worker 快取 App 外殼，當新版資產準備好時顯示「有新版 FamilyBoard 可以使用」和「立即更新」。按下按鈕後，等待中的 Worker 會啟用，頁面在控制權切換後重新載入。這是瀏覽器生命週期事件，不是資料庫還原，也不會清除家庭資料。更新 App 資產和備份家庭資料是兩件事，仍然要分開管理。

## 看到提示先讀目前狀態

更新提示不是資料損壞警告。先確認網路狀態、畫面上的家庭名稱和是否有剛輸入但尚未完成的資料。如果儲存健康卡片顯示沒有備份，或最近匯出已經很久，先匯出新的 JSON。提示本身不知道下載檔案是否放在可靠位置，所以不要把出現提示當成備份已完成。

## 按下立即更新會發生什麼

App 會把訊息傳給等待中的 Service Worker，讓新版接管頁面，接著偵測控制權改變並重新載入。瀏覽器依快取規則取得新的靜態資產，過程中不會建立帳號、不會把資料傳到伺服器，也不會觸發合併或取代還原。短暫重新載入或離線狀態是可能的，請等畫面穩定後再新增紀錄。若頁面沒有回來，保留備份，使用受支援的瀏覽器設定檔重新開啟已知網址。

## 更新和清除資料不要混為一談

不要為了「完成更新」而清除網站資料。清除瀏覽器儲存可能刪掉本機家庭，是另一個破壞性動作。也不要在沒有 JSON 備份時解除安裝 PWA。若舊平板只是家庭共用看板，先確認它是哪個設定檔；行政與私密紀錄不要在同一個公開畫面操作。

## 重新載入後抽查

檢查 App 版本、家庭名稱、一項未完成任務、今天的事件和最近維護項目。確認聯絡人與詳細備註仍在私密頁籤，共用看板沒有突然變成行政畫面。重新載入成功只表示新版 Worker 已接管，不代表所有家庭決策都已是最新。如果畫面不一樣，先記下觀察、版本與備份日期，再決定是否修改。

未來若在本頁旁放置相容平板、儲存媒體或密碼管理器的聯盟商品，會清楚揭露並可跳過。商品不能保證更新、保護瀏覽器資料或建立同步；免費 App 在支援的瀏覽器、受控設定檔與可靠備份下就能使用。家庭也可以在每次更新後指定一人讀出版本，另一人確認備份位置，形成簡單而可追蹤的更新紀錄。

如果更新後畫面短暫顯示離線，先等待網路恢復並重新整理，不要清除網站資料。若版本已改變但紀錄看起來少了，立即停止編輯，記下時間、瀏覽器設定檔和上次 JSON 匯出位置，再用唯讀驗證檢查副本。Service Worker 負責資產快取，並不會替你判斷哪一筆家庭資料應該保留；任何差異都要用備份和受控來源人工核對。共用看板、私密行政頁和離線快取也應分開檢查，避免把一次重新載入誤認為資料同步。

更新前後都不要在同一時間大量修改資料；先讓版本穩定，再逐項確認。若使用舊裝置看板，記下它最後更新時間，讓家庭知道是哪一台裝置需要複查，而不是把所有問題歸咎於版本變更。

若更新提示重複出現，先確認瀏覽器允許 Service Worker 完成，再以備份和版本資訊判斷，不要連續清除快取。

更新是資產變更，不是家庭資料驗證；因此每次重大版本後都應安排一次簡短的資料抽查和備份確認，並把結果寫在家庭維護紀錄，而不是只依賴畫面上的提示。

若家中由不同人維護多個裝置，還要記下每台裝置的版本和最後檢查時間，避免把其中一台成功更新誤認為整個家庭已完成更新。

如果家庭使用多個瀏覽器，還要記錄每個設定檔的版本、最後重整時間與最近一次 JSON 匯出日期；這些觀察只描述裝置狀態，不能取代真正的備份驗證。遇到長時間離線時，先保存本機資料，等版本與連線穩定再做小範圍複查，避免把更新問題和資料問題混在一起。

**情境 CTA：** 有需要時先匯出，按一次立即更新，等重新載入後檢查版本和幾筆代表性紀錄。
