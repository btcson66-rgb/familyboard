# 可列印家庭緊急聯絡表：先排好角色與備援，再決定哪一版可以分享

緊急聯絡表最重要的不是塞進最多電話，而是讓人在壓力下知道先找誰、找不到時找誰、哪一份資料仍要確認。這張表建議分成家庭共用版、受控完整版本和臨時交接版；不同版本的資訊量可以不同。列印前寫住宅或家庭代號、版本日期、保管人和適用期間，完整住址、門禁、帳號、付款、身分證件與詳細醫療資料只放在真正需要且能控制的地方。

## 角色與備援順序

| 角色 | 名稱／代號 | 聯絡管道或查找位置 | 何時聯絡 | 備援角色 | 最後複查 |
| --- | --- | --- | --- | --- | --- |
| 家庭主要聯絡 |  |  |  |  |  |
| 附近可信任的人 |  |  |  |  |  |
| 房東／管理單位 |  |  |  |  |  |
| 水電／瓦斯／網路 |  |  |  |  |  |
| 照顧者／寵物支援 |  |  |  |  |  |
| 其他家庭指定角色 |  |  |  |  |  |

「聯絡管道」不一定要直接寫完整電話，可以寫官方客服入口、帳單位置、家庭受控通訊或「由保管人提供」。如果一定要在受控版本保存電話，也要標註誰同意分享、有效期間和何時複查。家庭成員的職責、語言、可出席時間與住宅位置會變動，備援欄不要只寫一個永遠不在的人。

## 依情境演練

挑三個情境測試這張表：夜間漏水要找誰、停電要確認哪個官方來源、照顧者臨時不能到場時誰接手。請另一位家人不詢問建立者，從表上找到角色、來源、下一步和備援；若找不到，就記錄「缺來源」「電話未驗證」或「角色不清」，不要把整本家庭通訊錄印上去。使用[緊急聯絡表產生器](/zh-tw/tools/emergency-contact-sheet-generator/)可先生成欄位，但結果仍需人工確認。

火災、瓦斯味、冒煙、受傷、生命危險或需要撤離時，先依所在地緊急服務、官方公告、建築管理和合格專業指示處理。這張表不能判斷危險程度、提供醫療意見或取代消防與救援。公共服務電話也可能因地區、供應商或政策變動，請保存官方來源與檢查日期。

## 保存、更新與隱私

家庭變動、搬家、服務商更換、照顧安排更新或官方通知變更後，建立新版本並回收舊版。完成交接後收回含電話、地址、醫療或門禁資訊的紙本；需要長期追蹤的聯絡角色可放入 FamilyBoard 本機 App，重大變更後自行匯出備份。未來公開內容若有電話卡、資料夾或標籤推薦，會放在清單之外並揭露 affiliate 關係，不會插入私密 App 或生成紙本。

## 先做一次備援演練

列印後請一位沒有建立表格的人，依序找出主要聯絡、附近可信任的人、公共服務與備援角色，並說出每個角色何時使用。若某一個電話沒人接，表上是否寫了下一個選項？若公共服務只剩搜尋結果，是否能找到官方來源和適用地區？把演練時間、缺漏欄位和修正人寫在複查區，不要用「應該知道」代替交接。

緊急聯絡表可分成三種版本：家庭內完整受控版、給可信任家人的共用版、只含必要角色的臨時版。每一版都標示對象、有效期間和回收方式；照顧者不需要知道的住址、門禁、付款或完整病歷不要放進去。若紙本遺失，先盤點暴露了哪些資訊，再依家庭的受控流程更換門禁、通知聯絡人或撤回舊版。不要為了「備份」把同一份敏感資料散落在多個群組。

危急事件結束後，再用這張表記錄實際發生的聯絡順序、誰回覆、哪個來源失效和下一次要補什麼。這能讓下一版更短、更可靠，也能避免把一次演練的推測當成所有家庭情境的固定答案。FamilyBoard App 可以保存角色與複查任務，但不會自動撥電話、判斷危險或取代所在地緊急服務。

每次演練後由複查人簽名並寫日期，確認受控版本仍能找到；沒有驗證過的電話一律標示待確認，不要讓空白欄位被誤認為已經可靠。

把失效日期也寫清楚，讓接手者知道何時必須重新查證。
