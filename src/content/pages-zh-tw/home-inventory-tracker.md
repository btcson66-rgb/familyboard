# 家庭資產清單 App 教學：先記錄「日後一定會找」的設備資料

**最實用的起點：** 拿一台冷氣、冰箱或洗衣機當範例，只輸入名稱、位置、品牌、型號、序號與購買日；接著新增一筆保養和一筆保固，最後匯出備份。若這套資料真的能讓家人更快找到答案，再逐區增加，不必第一天盤點全屋。

家庭資產清單不是收藏品目錄，也不是為了追求筆數。它應該回答幾個會影響決策的問題：這是家中哪一台設備、放在哪裡、送修時要報什麼型號與序號、何時購買、保固與收據去哪裡找，以及過去做過哪些保養。FamilyBoard 把資產當成其他家庭紀錄的連結起點，而不是孤立的一列試算表。

## 哪些物品值得先建立資產紀錄？

可以用「未來一年是否可能需要查資料或花錢處理」判斷。通常值得優先加入的是：

- 冷氣、冰箱、洗衣機、除濕機、熱水器等需要保養或可能叫修的家電；
- 電腦、螢幕、網路設備等有型號、序號或保固期限的電子產品；
- 嬰幼兒用品、輔具或安全設備等需要確認批次、手冊或更換紀錄的物品；
- 車輛、儲能設備或較高價家具等可能牽涉文件、保險或搬運的資產。

不必把杯子、一般衣物或每件低價用品逐一輸入。若物品沒有辨識、保養、文件、保固、移交或更換規劃用途，精細建檔只會增加日後維護負擔。

## 在「家庭資產」快速新增一筆紀錄

開啟[繁中 App](/zh-tw/app/)後進入「家庭資產」。快速新增表單包含名稱、類別、位置、品牌、型號、序號、購買日期與備註；只有名稱必填，繁中介面的類別預設為「家電」。

建議依下列方式寫：

| 欄位 | 實用寫法 | 避免的寫法 |
|---|---|---|
| 名稱 | 客廳冷氣、廚房冰箱 | 冷氣 1、設備 A |
| 位置 | 客廳靠陽台、廚房 | 家裡 |
| 品牌／型號 | 依機身銘牌原樣抄錄 | 憑外觀猜測系列名稱 |
| 序號 | 確認字母、數字與 0/O | 把帳號、密碼一起貼入 |
| 購買日 | 依發票、訂單或安裝單 | 不確定卻填一個精確日期 |
| 備註 | 排水管走向、文件位置線索 | 門鎖密碼、完整付款資料 |

送出後，資產卡會顯示狀態、類別、位置、品牌、型號、購買日，以及已填寫的序號與備註。這是家庭私密工作區中的完整卡片；共用家庭看板與交接摘要不會因為資產卡有序號，就自動把序號展示出去。

## 關注與封存不是刪除

每張資產卡有「關注」與「封存」兩個動作。「關注」適合暫時需要觀察的設備，例如冰箱出現異音、牆面修補後要追蹤是否再滲水，或近期可能評估更換的洗衣機。它仍是有效資產，會計入今日總覽，也能在保養、保固與文件的新增選單中被選取。

「封存」適合已汰換、出售、搬離或不再由這個家庭管理的物品。封存後卡片仍留在資產頁，既有關聯紀錄也不會被刪除；但它不再計入有效資產，也不會出現在其他功能新增紀錄時的有效資產選單。誤封存時，可以按「關注」把它改回關注狀態，再依需要清除關注回到有效狀態。

## 把保養、保固與文件連回同一台設備

建立資產後，再到「保養維護」「保固」或「文件」選取該資產。三類紀錄會保存在各自分頁，清單上以資產名稱顯示關聯。例如：

1. 建立「客廳變頻冷氣」，抄錄室內機正確型號與購買日；
2. 在保養維護新增「依原廠說明檢查濾網」，填入來源與下次日期；
3. 在保固新增提供者、書面起訖日及收據位置；
4. 在文件新增「客廳冷氣說明書」，只記可靠的檔案或紙本位置。

FamilyBoard 目前沒有一個把同一資產所有保養、保固與文件集中顯示的「資產詳情頁」。使用時要切換分頁，並以一致、明確的資產名稱作為連結線索。這個限制應先知道，才不會以為點資產卡就能看到完整歷史。

## 照片、發票與說明書原檔放在哪裡？

資產表單沒有照片上傳功能，文件功能也是索引，不會把 PDF、照片或掃描檔存進 FamilyBoard。可把原檔放在加密雲端、外接儲存裝置或妥善保管的紙本資料夾，再記錄「家用雲端／家電／客廳冷氣／發票」或「書房藍色資料夾第 2 格」等家人能理解的位置。

位置索引不要直接包含雲端密碼、完整證件號碼、信用卡資訊或門鎖密碼。本機資料代表不經 FamilyBoard 帳號雲端同步，不代表拿到目前瀏覽器的人看不到內容。

## 需要更多欄位時，用家庭資料總表複查

資產底層紀錄還支援購買價格、賣方、安裝日期與手冊參考等欄位，但快速新增表單沒有顯示。需要時可到「設定」匯出家庭資料總表 CSV，在試算表中補齊，再依匯入預覽確認欄位與關聯。

CSV 是批次檢查與編輯格式，不是完整災難復原備份。每次大量修改前，先匯出完整 JSON；匯入後抽查至少一筆資產、關聯保養與保固是否正確。可依[數位家庭資產備份教學](/zh-tw/guides/digital-home-inventory-backup/)建立可還原的流程。

## 家庭資產清單不能替你做的事

FamilyBoard 不會掃描家中設備、辨識照片、查詢序號真偽、估算二手價、判斷保固是否成立，也不會自動把資料交給保險公司。若要理賠、送修或確認召回，仍需以發票、保證書、原廠資訊、業者條款與主管機關資料為準。

它真正提供的是一個能持續維護的索引：把「是哪一台、資料在哪裡、誰負責、什麼時候再看」留在同一個家庭工作流程。高品質的十筆紀錄，通常比無人複查的五百筆清單更有用。

## 常見問題

### 家庭資產清單需要把每一件物品都輸入嗎？

不需要。先記錄故障、遺失或更換時會造成明顯成本，而且日後需要查型號、序號、保固或保養歷史的設備。

### 資產卡上的關注與封存有什麼差別？

關注仍是有效資產；封存會退出有效數量與新增紀錄的資產選單，但不刪除既有資料。

### FamilyBoard 可以上傳家電照片或收據嗎？

目前不行。請把原檔放在可靠位置，再於資產備註或文件索引留下可找回的線索。

### 資產清單會自動同步到其他手機或電腦嗎？

不會。更換裝置或瀏覽器前，要自行匯出完整 JSON 或加密 JSON 備份。
