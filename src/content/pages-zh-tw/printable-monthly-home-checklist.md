# 可列印每月家庭檢查表：30 分鐘整理下個月真正要注意的事

每月家庭檢查不需要變成一次完整的房屋巡檢，也不必把所有家務重新列一遍。這張表的用途，是在固定而短的時間內問五個問題：家中有沒有新出現的狀況？本月到期或已完成的保養有沒有留下紀錄？接下來 45 天有哪些續訂或行政期限？重要聯絡與文件位置是否仍正確？下個月最值得先處理的三件事是什麼？

建議列印一張放在家庭管理區，準備一支筆和手機裡的行事曆或 FamilyBoard。先寫日期與參與者，再用 30 分鐘完成；若當月只有一人負責，也要把需要別人確認的項目寫出來。這張表不預設每個家庭都有車庫、庭院、中央空調或相同的帳單，請刪除不適用項目，不要為了填滿空格而製造工作。

## 一、居家狀況：只記錄「有變化」的地方

- [ ] 是否看到漏水、潮濕、裂痕、鬆動、異味或其他和上月不同的狀況？
- [ ] 電器或設備是否出現新的聲音、氣味、錯誤訊息或使用異常？
- [ ] 上月留下的維修是否已完成？若沒有，下一步是誰在什麼日期前聯絡誰？
- [ ] 有沒有因颱風、豪雨、地震、停電或搬動家具而需要補記的損壞？

這一段不是要你拆開設備或攀爬檢查。只記錄看得到、聽得到或家人已回報的變化；涉及瓦斯、電氣、結構、黴菌或高處作業時，先停止自行處理並尋求適當協助。若發現異常，紙本上的一句「客廳冷氣滴水，8/12 聯絡原廠」比含糊的「處理冷氣」更容易交接。

## 二、保養與服務：把結果留下來，不只寫「已處理」

- [ ] 查看本月到期或已逾期的保養項目。
- [ ] 為已完成的清潔、濾網更換、檢查或叫修寫下日期與簡短結果。
- [ ] 確認下次服務預約、保養廠商與需要準備的物品。
- [ ] 把需要追蹤的報價、回訪或零件等待建立為一項有日期的任務。

不要把所有設備都安排成同一個月處理。原廠建議、租約、所在地規定與設備使用強度可能不同；這張表只是提醒你查看來源，不是替你制定固定週期。完成後可在 App 的保養分頁保留歷史，讓下次查看時知道「做過什麼」而非只剩一個打勾。

## 三、家庭行政：查看未來 45 天，而不是等扣款才想起

- [ ] 檢查未來 45 天的訂閱續約、保險、租約、學費或其他家庭期限。
- [ ] 記下本月新增的大型採購、保固收據與說明書位置。
- [ ] 清理已完成、重複或已不適用的家庭任務。
- [ ] 確認家庭成員、服務商、緊急聯絡與付款提醒是否有變更。

訂閱檢查的目標不是看到費用就立刻取消，而是確認服務仍有用、續約日是否能在做決定前留出時間、管理連結是否找得到。不要在紙本上抄寫信用卡卡號或完整敏感資訊；留下服務名稱與安全的查找位置即可。若要比較跨月份費用，可把數字輸入 App 的訂閱紀錄，但不同幣別不要直接相加當成精確家庭預算。

## 四、聯絡與交接：讓另一個人能接著做

- [ ] 本月是否有新的保母、清潔、維修、管理員或照顧安排？
- [ ] 家人是否知道重要設備的名稱、位置與目前待處理事項？
- [ ] 下個月是否有旅行、住院、搬家、考試或節日，需要臨時交接？
- [ ] 最近一次 JSON 或 CSV 備份是否能在你預期的位置找到？

交接不是把整張表拍照丟進群組。請只分享對方需要的資訊，敏感聯絡人、序號、私人備註與付款資料不要出現在公開紙本。FamilyBoard 的家庭交接模式能依分享設定檔產生較低敏感度的摘要；列印前仍請逐格檢查。

## 五、下個月只選三件事

在最後留下三個真正可執行的項目：一件能避免損害擴大的事、一件有明確期限的行政事、一件能讓其他人更容易接手的整理事。每件寫上負責人、下一步和日期。例如「小明｜8/18 前確認熱水器檢修報價」，不要寫「處理熱水器」。若三件以外還有想法，放進完整任務清單，不要讓本月檢查表失去短小的目的。
