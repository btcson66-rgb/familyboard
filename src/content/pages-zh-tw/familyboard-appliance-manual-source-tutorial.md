# FamilyBoard 家電手冊來源教學：先對正確型號與版本

家電手冊只有在屬於正確設備而且仍是目前版本時才有幫助。FamilyBoard 的免費手冊來源查核紀錄，保存設備 ID、型號證據、來源發行者、版本或複查日期、安全提醒和下一步。它不認證安裝、不診斷故障，也不取代合格技師；製造商、主管機關和最新緊急指示才控制手冊與現場警告衝突時的處理。

## 從家庭物品識別開始

先從受保護的家庭物品紀錄確認品牌、完整型號，必要時再看修訂版或序號範圍。使用 `KITCHEN-AP-02` 這類中性 ID，完整序號和地址留在受保護來源。相似面板照片、產品家族名稱或零售商標題都不足以配對說明。銘牌被遮住、磨損或看不清時，記下限制並安排安全的找回工作。

## 優先使用製造商目前來源

記錄手冊來自製造商官網、官方服務入口、隨機紙本或主管機關通知中的哪一種，並留下來源網址或受保護檔案指標、公布或更新日期、語言和地區。第三方 PDF 可以提供線索，卻可能過期、缺頁或是不同電壓版本。來源互相矛盾時保留兩份，請製造商或合格服務角色確認控制版本，不要默默選最容易看的那份。

## 記錄限制，不要把圖解當 DIY 授權

手冊可以提醒不要拆外殼、電線破損時不要操作，或只能使用特定零件。這些文字不能讓家庭自行處理瓦斯、電氣、冷媒、結構部件或高速機械。聞到異味、看到煙霧、裸露導體、漏水或有人受傷時，先停止並依所在地緊急與專業指示處理。來源配對只證明文件對得上，不證明家電此刻安全。

召回、型號改版、服務到府、搬家或製造商更新後要重新複查。在交接中分享中性設備 ID、語言和來源指標，不要放完整序號、地址或帳戶資料。重要歷史可以匯出受保護備份。未來可能在紀錄外出現標籤機、濾網或手冊收納用品的聯盟推薦區，必須清楚揭露且可略過；它不能驗證相容性，也不能取代正式指示。

## 讓接手者重做一次比對

請另一位家人依中性 ID 打開來源，說出手冊型號、版本和安全限制。若他只能詢問建立者才找得到，代表索引仍有缺口；建立新的來源查找工作並指定日期。不要把接手者的理解直接當成技師認證，這項演練只確認家庭能找到相同文件和目前說明。

如果家電曾經搬到另一個住處、換過電源環境、接受過維修或出現召回通知，請在來源紀錄增加事件日期和新的比對結果。不同地區可能有不同電壓、語言、保固條款與安全提醒，不能只因為型號前幾碼相同就共用整份指示。紙本手冊若受潮或缺頁，記錄它仍可讀的範圍，並把補充版本交給保管原件的人確認。

交接時可以請接手者回答三個問題：這份文件對應哪一台設備？它的版本和更新日在哪裡？遇到異味、煙霧、漏水或裸露電線時要停止並找哪個官方或專業來源？如果答不出來，就把問題列為待修正，而不是把手冊標成已驗證。這樣能把「找到 PDF」和「理解限制」兩件事分開，降低家庭誤用說明的風險。

建立來源索引時，還可以記錄手冊涵蓋的語言、地區與附件清單。缺少安裝章節、警告頁或保固頁時，不要用網路上另一台機器的文件補洞；先把缺頁標成來源缺口。家庭只要能清楚說出「目前找到什麼、還缺什麼、由誰向製造商詢問」，就比一份看似完整卻型號不明的 PDF 更安全。

複查日期也要隨召回或服務變更更新，並把版本差異交給負責人。

不要把相似型號的說明混在同一個索引。

版本清楚，家人交接才不會誤用。

把來源與版本寫進索引，日後才能快速複查。

**情境 CTA：** 把一件家電和正確手冊來源配對，記下安全界線，並把型號或版本缺口交給負責人。
