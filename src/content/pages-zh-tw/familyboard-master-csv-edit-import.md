# FamilyBoard CSV 家庭資料總表怎麼編修？

FamilyBoard 的主檔 CSV 適合在需要一次複查多筆資料、補上快速新增表單沒有顯示的欄位，或準備家庭交接時使用。它不是普通的名單，也不是完整備份。試算表把資料攤平成一列一列，很容易讓人忘記資產、保養、保固、訂閱、任務、聯絡人、文件與交接設定其實彼此有關。本篇用台灣家庭常見的「先備份、少量編修、預覽、驗證」流程，避免一次改壞整個工作區。

## 先留一份不可編修的 JSON 安全快照

開啟 App 的「設定」，先匯出完整 JSON 備份。檔名可以使用 `FAMILYBOARD-BACKUP-2026-08-29.json` 這種中性格式，放到家庭真正能取回的私密位置，不要直接在這份檔案上修改。JSON 才是 App 目前可以還原的完整資料格式；CSV 是檢查與批次編修工具，不能取代災難復原檔。

若你還沒有確認瀏覽器儲存狀態，就不要在同一時間開始大規模改表。先確認儲存空間提示、檔案確實下載到指定位置，並在匯入完成與複查結束前保留原始備份。看到瀏覽器跳出「下載完成」不代表檔案一定在你以為的資料夾，也不代表稍後一定能成功還原。

## 先看懂主檔，再碰任何儲存格

主檔會把原本分散在不同分頁的資料集中：家庭成員、資產、保養任務與事件、保固、訂閱、聯絡人、文件與交接設定。每列都有資料類型與穩定 ID。資產的保養紀錄可能用資產 ID 指向它；如果只在試算表裡排序沒有問題，但把 ID 改成自訂名稱，可能造成重複紀錄或斷掉關聯。

可以用 CSV 補上已從來源確認的購買價格、安裝日期、說明書連結、負責角色、狀態或安全來源代號。不要因為某一欄方便，就貼入密碼、卡號、完整地址、身分證字號、病歷敘述、私訊全文或門禁資訊。CSV 另存一份後，比瀏覽器畫面更容易被轉寄、同步或誤放在共用資料夾；「只在本機」不等於每一份下載檔都安全。

## 一次只做一個可說明的變更範圍

每次複查只處理一種目的，例如補三項家電安裝日期、修正兩筆未完成任務的負責角色，或為幾筆保養列加上目前說明書的來源代號。把變更原因與日期寫在受保護的複查筆記，不要把長篇私密故事塞進不確定用途的 CSV 欄位。不要因為「已寄出申請」就把狀態改成完成；完成仍應描述實際觀察到的結果。

保留 App 產生的欄位名稱與分隔格式。試算表的自動日期、公式、合併儲存格、貨幣格式與複製貼上，可能把原本的值改成 App 不接受的文字。檢查日期格式、金額是否仍是數字、可選欄位是否真的留白。另存 CSV 時也可能加入不同編碼或換行符號，交給匯入預覽檢查，不要靠猜測修正。

## 把驗證預覽當成正式複查，不要直接按下去

匯入有兩個階段。第一階段是解析與預覽，App 會提示欄位錯誤、未知資料類型、重複 ID 或無法對上的關聯。看不懂的錯誤就先停下來，在試算表修正後重新預覽，不要為了讓紅字消失而刪掉整列。

預覽乾淨後，再把列數和幾筆已知紀錄與原本 App 對照。想在現有資料旁新增或更新時，才考慮合併；只有確定這份檔案要成為新來源時，才考慮取代。取代流程會先建立安全快照，但選錯檔案仍可能讓工作區變得混亂，快照不是替你判斷哪份資料正確。

## 匯入後核對關聯，不只看總筆數

提交後開啟 Today 及相關分頁，至少抽查一筆資產與保養、一筆保固或訂閱日期、一筆負責角色和一筆文件來源。確認標籤可讀、日期出現在預期分頁，原本應保持開放的工作沒有被誤關閉。若發現錯誤，不要繼續在同一份問題 CSV 上疊改；改用匯入產生的安全快照或未修改的 JSON 備份復原，再定位是哪個欄位造成問題。

編修完成後，CSV 只保留到複查需要的時間。若檔案含有私人聯絡人、購買資訊或家庭交接內容，依家庭的保存政策保護或刪除舊副本。未來可能出現在頁面旁的試算表、標籤機或儲存媒體推薦，必須清楚標示業配或聯盟關係、放在操作區外並可跳過；商品不能驗證關聯，也不能讓備份突然可還原。

**下一步：** 匯出 JSON、再匯出主檔 CSV，只修改一個低風險欄位，通過預覽，核對三筆關聯資料，最後決定是否還需要保留編修檔。
