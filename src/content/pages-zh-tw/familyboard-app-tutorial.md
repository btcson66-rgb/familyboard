# FamilyBoard 使用教學：先建立一套會持續使用的家庭管理流程

**最快的開始方式：** 不要第一天就盤點全家。先建立家庭與成員，加入一項最怕忘記保固或保養的設備，設定一個有來源的保養工作，完成後匯出第一份 JSON 備份。這四步跑得順，再加入其他家務。

FamilyBoard 是免費、免帳號、本機優先的家庭管理 App。它把資產、保養、保固、訂閱、任務、聯絡人、文件索引與家庭交接放在同一個瀏覽器工作區，但不會替你掃描全家、自動讀取信箱、同步其他行事曆或在雲端保存資料。了解這些界線，才能把它用成可靠的家庭紀錄，而不是另一份很快被放棄的清單。

## 開始前先知道資料放在哪裡

繁中 App 位於 `/zh-tw/app/`。家庭紀錄寫入目前瀏覽器的 IndexedDB，同一裝置上的英文與繁中介面會讀取同一份資料。App 不載入公開網站的 GA4 或廣告程式碼，也不把內容放進 sitemap。

本機優先不等於自動備份。清除網站資料、換瀏覽器、重設裝置或儲存空間被移除，都可能讓紀錄消失。正式輸入重要資料前，先確認你知道「設定」在哪裡，以及日後要把備份存到哪個可靠位置。

## 第一步：建立家庭與真正的負責人

第一次開啟 App 時，輸入家庭名稱；也可以用逗號加入幾位成員。建立完成後，從「成員」補上負責家庭工作的實際人員。

成員不是通訊錄，而是指派責任的基礎。保養、訂閱與任務若長期都寫「任何人」，常見結果是沒有人真的處理。可以先從角色而非全名開始，例如「主要管理者」「備援成員」或「租屋聯絡人」，等流程穩定後再調整。

## 第二步：只加入值得追蹤的家庭資產

在「家庭資產」建立第一筆設備。適合優先記錄的是故障成本較高、需要保養、有保固、會搬家或理賠時需要辨識的物品，例如冷氣、冰箱、洗衣機、熱水器、電腦或車輛。

一筆實用資產至少包含：

- 清楚名稱與所在位置；
- 品牌、型號與必要時的序號；
- 購買或安裝日期；
- 能找到原廠手冊、收據或保證書的線索；
- 不含密碼與完整帳號的操作備註。

不必把每把湯匙都建檔。FamilyBoard 的價值來自「日後能作決定的歷史」，不是資料筆數。

## 第三步：建立有來源的保養工作

在「保養維護」加入工作時，可以連結既有資產、指定負責人、設定下次到期日、優先順序與「完成後間隔月數」。說明來源欄應放原廠手冊、官方支援頁或服務商建議，避免半年後沒有人知道週期從哪裡來。

按下「標記完成」時，App 會留下完成紀錄；若設定了間隔月數，也會從完成時間推算下一次到期日。這和一般「任務」不同：家庭任務的重複週期目前只是文字備註，完成後不會自動產生下一筆。需要真正保留週期歷史的設備工作，應放在保養功能區。

不知道從哪個項目開始，可以先看[台灣家庭的居家保養排程建立方法](/zh-tw/guides/home-maintenance-schedule/)。涉及電力、瓦斯、冷媒、消防設備、結構或高處作業時，紀錄應提醒你停止使用、觀察與聯絡合格人員，而不是把危險拆修步驟寫成家務。

## 第四步：把保固與文件放回同一個設備脈絡

在「保固」選擇資產後，記錄提供者、起訖日期、收據位置與條款來源。App 顯示的日期狀態是提醒，不會替你判定業者是否接受申請。若只知道購買日與保固月數，可以先用[免費保固到期日計算器](/zh-tw/tools/warranty-expiration-calculator/)估算，再把書面依據一起保存。

「文件」目前是索引，不是檔案上傳空間。你可以記「保證書在加密雲端資料夾／家電／冰箱」或「紙本發票在書房藍色資料夾」，但原始檔仍留在你選擇的儲存位置。這樣做的目的，是讓家人知道去哪裡找，而不是在瀏覽器再複製一份敏感文件。

## 第五步：用任務、行事曆與訂閱整理家庭責任

「任務與行事曆」適合單次責任與家庭事件。任務可以指定負責人、到期日與重複備註；行事曆事件則保存開始時間、結束時間與地點。它不是 Google Calendar、Outlook 或 iCloud 的替代品，目前不會同步或發送通知。

「訂閱」可以記服務名稱、金額、幣別、計費週期、續約日、提前複查天數與負責人。App 會計算有效訂閱的年化總額，但不會登入服務、取消訂閱或驗證價格。付款備註只應寫「家庭共用卡」這類非敏感提示，絕對不要輸入卡號、驗證碼或密碼。

## 第六步：建立能安全交給別人的資訊

「緊急聯絡」可保存人員或服務單位、電話、電子郵件與操作備註。標記為「敏感」的聯絡人，預設不會出現在家庭交接摘要。這個標記是分享篩選，不是加密功能；能開啟目前瀏覽器 App 的人仍可能看到私密工作區內容，因此裝置本身也要有適當鎖定。

「交接」可以建立不同用途的設定檔，例如「週末寵物照顧」「主要管理者住院時的備援」或「搬家當日」。每個設定檔決定是否包含未完成任務、保養工作、非敏感聯絡人與文件位置。

交接摘要刻意排除敏感聯絡人、序號、文件細節、訂閱費用、私密備註與備份內容。列印或交付前仍要重新確認日期、電話與任務標題，因為系統不會替你判斷每一句話是否適合分享。

## 第七步：共用家庭看板前先做可見內容檢查

「家庭看板」以大字顯示家庭名稱、今日日期、未完成任務、今日事件與近期保養，適合放在共用平板。它不顯示保固、訂閱、文件與聯絡人，但任務或事件的**標題本身**仍可能透露敏感資訊。

例如「領慢性處方藥」即使只是普通任務，放在客廳螢幕仍可能讓訪客看到。啟用共用看板前，逐項檢查標題，必要時改成只有家人理解的中性描述。

## 第八步：建立真正可復原的備份習慣

「設定」提供四個不同用途的動作：

| 功能 | 適合用途 | 重要限制 |
| --- | --- | --- |
| 匯出 JSON | 完整復原與搬移資料 | 內容可直接讀取，必須妥善保護 |
| 匯出加密備份 | 保存較敏感的完整資料 | 忘記密碼無法由 FamilyBoard 找回 |
| 家庭總表 CSV | 試算表檢查與批次編輯 | 不是完整備份，匯入前要看驗證預覽 |
| 要求持久儲存 | 降低瀏覽器主動回收空間的機會 | 是否核准由瀏覽器決定，仍不能取代備份 |

建議在完成初次設定後立即匯出一次；之後只要新增大量紀錄、匯入 CSV、換裝置或準備清除瀏覽器，就先建立新備份。不要等到資料遺失才第一次測試還原流程。

## 一套 15 分鐘的初次設定範例

1. 建立「我們的家」與兩位責任成員。
2. 新增「客廳冷氣」，記下型號與原廠手冊位置。
3. 依原廠來源建立一項濾網檢查或專業保養提醒。
4. 新增保固截止日與收據存放位置。
5. 建立「主要管理者不在家」交接設定檔，只包含必要項目。
6. 匯出 JSON，將檔案移到瀏覽器以外的可靠儲存位置。

完成這六件事，FamilyBoard 就已經能回答「這台設備是什麼、誰負責、下次何時處理、上次做了什麼、文件在哪裡，以及管理者不在時誰能接手」。這比第一天輸入 200 筆沒有後續用途的物品更有價值。

## 常見問題

### FamilyBoard 需要註冊帳號或付費嗎？

目前不需要。瀏覽器版 App 可免費使用，沒有登入、結帳或核心功能牆；家庭資料保存在目前瀏覽器。

### 第一次使用 FamilyBoard 應該先輸入全部家用品嗎？

不用。先建立家庭與負責人，再加入一項高價值設備、一個保養工作與一份備份；確認流程適合後再逐步擴充。

### 完成保養工作後，下次日期會自動更新嗎？

如果保養工作有設定完成後間隔月數，按下完成會留下完成紀錄並推算下次到期日；一般家庭任務的重複週期目前只是備註，不會自動建立下一筆任務。

### 家庭看板可以顯示在客廳平板嗎？

可以，但它只降低敏感資料類型，不會檢查任務或事件標題是否透露私事。放到共用螢幕前，仍要逐項檢查可見文字。

### CSV 家庭資料總表可以取代 JSON 備份嗎？

不可以。CSV 適合用試算表檢查與批次編輯；完整復原仍應使用 JSON 或加密 JSON，並保存在瀏覽器以外的可靠位置。
