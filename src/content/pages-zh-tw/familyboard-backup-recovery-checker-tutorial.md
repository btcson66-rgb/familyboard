# FamilyBoard 備份還原檢查器怎麼用？

「我們以前有匯出過」和「另一位家人現在能找回可用版本」是兩件不同的事。FamilyBoard 的備份還原檢查器把這兩個說法拆開，讓家庭先定義要保留的範圍，再測試副本、記錄實際看到的結果，最後把下次演練交給真正能執行的人。工具只處理你輸入的文字，不會讀取硬碟、開啟檔案或連線上傳。

## 先決定最小必要範圍

匯出前先寫下這次需要找回的最小範圍，例如一項設備、一項未完成任務、一個文件指標與一個緊急聯絡揭露界線。這不是要複製所有檔案，而是確認瀏覽器資料遺失或換裝置後，家庭仍能繼續工作。範圍文字使用「設備與維護」「文件指標」等中性描述，不要貼完整地址、帳號、付款資料、病歷或私人通信。

## 匯出不編修的 JSON

打開 FamilyBoard Settings，匯出完整 JSON 備份，依家庭受保護保管流程加上中性版本與日期。先不要用文字編輯器修改它。CSV 適合有意識的表格修正，但不能取代 JSON 復原檔，因為欄位關聯與部分資料可能無法完整保存。

在檢查器填寫真正匯出日與 `BACKUP-2026-A` 這類保管代號，不要填加密密碼、公開分享連結或完整檔案路徑。匯出日只表示檔案產生時間，不表示它已經完整、加密、可被所有家人取用或確實放在安全位置。

## 用副本測試，避免覆蓋工作資料

在家庭適合的測試環境開啟副本，保留原本瀏覽器資料與未編修匯出檔。依照剛才的範圍檢查：設備名稱與版本是否可辨認、未完成任務與 owner 是否存在、文件指標是否找得到、緊急聯絡資料的敏感界線是否仍符合預期。只記錄看見的結果與版本，不要把「畫面有出現」寫成「全部資料一定完整」。

如果只成功開檔，尚未核對內容，狀態應保持「已找回，等待內容核對」。發現關聯遺失、版本過舊或某範圍未測試，就留下缺口與下一步，不要刪除原始備份後重新猜測。新裝置要成為主版本前，也要在那台裝置重新測試；FamilyBoard 沒有自動跨裝置同步。

## 理解四個日期

最近匯出日是產生快照的日期；找回測試日是有人實際開啟或還原副本的日期；本次檢視日是家庭讀取準備狀態的日期；下一次測試日是未來要執行的計畫。工具只檢查日期順序，不判定法律期限、資料完整性或災害應變是否充分。最近匯出但沒有找回觀察，仍然只是未測試的假設。

## 交接下一次演練

指定一位能取得受保護儲存位置的角色，讓他讀懂工具輸出的範圍、實際觀察、未解缺口與日期。請備援角色在不拿到密碼或完整私密文件的情況下，找出原件並說明可以查看的最小範圍。家庭換裝置、成員角色、保管位置或重要紀錄種類改變時，提前重新開啟檢查，不要等到固定日期才發現路徑失效。

JSON 匯出含有整個本機資料庫，應與瀏覽器分開並妥善保護。檢查器不是加密工具、雲端同步、權限系統或災難復原保證。未來備份硬碟或軟體的聯盟推薦必須在表單外清楚揭露且可略過，購買商品不會自動讓家庭備份變成可還原。

如果家庭由不同人輪流管理，請把「誰可以取用」「誰只看摘要」「誰負責最後確認」分開寫在受保護流程，而不是只在檢查器裡放一個姓名。這樣角色離開、裝置更換或檔案移動時，家人仍知道要重新核對哪個授權與來源。任何無法證明的範圍都保持開放，誠實的缺口比假裝完成更容易修正。

演練結束後，請記錄測試使用的是哪一份副本、核對了哪些資料、是否有欄位或關聯沒有出現，以及遇到問題時由誰負責修正。不要把測試檔留在共用下載資料夾，也不要把完整備份寄給不需要它的人；完成可找回的目標，是讓正確的人在正確位置取得正確版本。

**下一步：**完成一次真正的副本找回測試，補上四種代表資料的觀察，並把下一個演練日期交給有權限且能執行的家庭角色。
