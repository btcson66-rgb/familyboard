# 家庭文件索引教學：記住原始文件在哪裡，不把 App 當成檔案庫

## FamilyBoard 是地圖，不是文件保險箱

家庭文件常同時存在紙本抽屜、電子郵件、雲端硬碟與某位家人的電腦。如果所有內容都複製進同一個工具，會擴大敏感資料風險，也容易出現多個版本；但只靠「應該在信箱」的記憶，又無法在需要時找到。

FamilyBoard 的「文件」功能採索引方式：保存文件叫什麼、屬於哪一類、原始版本放在哪裡、和哪個家庭資產有關、何時要複查，以及非敏感備註。它不提供檔案上傳，完整 JSON 備份也只包含索引文字。

## 先設計少量、家人看得懂的分類

可從八類開始：住宅與租約、家電與購買、保固、保險、維修服務、公用事業、車輛與交通、緊急與照護。分類名稱要用家庭實際會問的語言，不要用「PDF、掃描、2026」等只描述檔案形式或年份的抽屜。

測試方式很簡單：請沒有建立分類的家人回答「熱水器手冊應該放哪一類」。如果必須由建立者解釋兩分鐘，分類可能太細或名稱太像。FamilyBoard 不會限制分類數量，也不會自動替你分類，因此一致命名比增加更多選項重要。

## 在 App 建立第一筆文件索引

進入繁中 App 的「文件」，展開「新增文件索引」：

1. 「紀錄名稱」必填，寫成日後搜尋的名稱，例如「廚房冰箱購買發票」或「租屋火災保險 2026」。
2. 「分類」預設家庭文件，可改成家庭共同採用的分類。
3. 「原始文件存放位置」必填，要具體到另一個人能重現。
4. 「關聯資產」選填；手冊、收據、保固或維修發票應連到相同設備。
5. 「複查日期」選填，依真正事件設定，而不是所有文件固定一年。
6. 「備註」可記版本、取得來源、未完成事項或查核原因，不放完整敏感內容。

儲存後卡片會顯示名稱、分類、原始位置、關聯資產、複查日及備註。關聯只顯示在文件卡與輸出資料中；目前家庭資產頁不會反向列出所有文件，因此需要查找時仍要進「文件」頁。

## 位置索引要寫到可以重現

「雲端」、「信箱」或「書桌」都太模糊。較好的電子位置是「家庭雲端／住宅／保固／fridge-warranty-2026.pdf，2026-08-22 核對」，或「寄件者某保險公司，主旨『電子保單』，2026 年 7 月」。紙本可以寫「防火文件盒／住宅分隔頁／透明袋 2」。

不要把保險箱密碼、門鎖碼、帳號密碼、完整身分證號或復原金鑰直接當成位置索引。可寫「由大人 A 管理的加密保管庫內，項目名稱……」，而把真正憑證留在權限、加密與復原機制更合適的工具。

若文件只有單一裝置的一份，位置寫得再清楚仍可能因硬碟損壞而消失。數位發展部資通安全署的備份指引建議採 3-2-1 原則並進行復原演練；可參考[重要資料備份指引](https://web.moda.gov.tw/ACS/press/news/press/19496)。索引與原始檔要分別設計備份，因為 FamilyBoard 不會替索引路徑抓取檔案。

## 關聯資產何時有用

洗衣機的發票、保證書、說明書與維修發票都選同一個洗衣機資產，日後看到文件卡便能確認對象；不要用檔名猜是哪一台。建立文件前，先到「家庭資產」把名稱、型號與位置寫清楚，尤其家中有兩台同品牌冷氣時。

關聯資產目前不是資料夾，也不會在資產卡自動產生附件清單。它是可匯出、可交接的結構化關係。若設備封存，既有文件紀錄仍保留，但封存設備不再出現在新增紀錄的選單中；這能保留歷史，又避免新資料繼續連到已停用資產。

## 複查日要對應一個理由

保單可在續約前複查，租約可在通知期限前複查，設備手冊通常不需任意設一年到期；一次性維修發票若沒有事件，也可以不填日期。日期的用途是觸發一次真實決定，不是讓每筆文件看起來完整。

目前文件複查日不會進今日總覽，也沒有通知。需要行動時，在「任務與行事曆」建立同日任務，例如「確認租約續租條件與最新版本」，指定負責人並在完成後更新文件位置或備註。不要依賴自己會記得打開文件頁。

## 交接時只分享必要位置

「家庭交接」設定檔預設不包含文件位置。只有你把「包含文件位置」設為是，摘要才會列出文件名稱、分類、位置、關聯資產與複查日；文件備註不會進入摘要。

這個排除能減少私密內容外流，但位置本身也可能敏感。例如「保險箱／護照袋」會告訴接收者重要文件所在。列印或交給臨時照顧者前，逐項問「對方完成這次工作真的需要知道嗎？」不同接收者應建立不同交接設定檔，不要把完整家庭索引交給每個人。

可依[家庭交接清單教學](/zh-tw/features/household-handoff/)先產生低敏感版本，確認紙本沒有序號、完整行程、醫療細節或過多文件位置再分享。

## 備份與修正的真實界線

FamilyBoard 的 JSON 備份會帶走文件索引與備註，但原始 PDF、照片、電子郵件與紙本不會跟著進檔案。還原成功只證明索引資料回來，不代表每個路徑仍可開啟。每次搬移雲端資料夾、改電子郵件帳號或移動紙本後，都要抽查幾筆位置。

目前文件卡沒有直接編輯或刪除按鈕。填錯可透過家庭總表 CSV 保留穩定 ID 更新；匯入前先預覽，並下載安全快照。涉及大量敏感位置時，CSV 本身也要視為私人資料，完成後放到受保護位置，不要留在共用下載資料夾。

## 常見問題

### 文件索引會把 PDF 或照片存進 FamilyBoard 嗎？

不會。App 只保存紀錄名稱、分類、原始文件位置、關聯資產、複查日期與備註；實際 PDF、照片與紙本仍在你控制的儲存位置。

### 複查日期到了會自動提醒嗎？

不會。文件卡顯示複查日期，但目前不會進入今日總覽或傳送通知。需要提醒時，請另外建立同日家庭任務並指定負責人。

### 交接摘要會顯示所有文件內容嗎？

不會。只有交接設定檔主動選擇「包含文件位置」時，才會列出文件名稱、分類、位置、關聯資產與複查日；文件備註不會進入交接摘要。位置本身仍可能敏感，列印前必須逐項檢查。

### JSON 備份是否也會備份索引指向的原始檔案？

不會。JSON 只備份 FamilyBoard 內的索引與備註，不會抓取雲端硬碟、電子郵件、電腦資料夾或紙本文件。原始檔案必須有自己的備份與復原測試。

**下一步：** 先為最難重新取得的一份手冊、保單或收據建立索引，請另一位家人實際找到原始版本，再依[備份還原教學](/zh-tw/guides/digital-home-inventory-backup/)驗證 FamilyBoard 索引備份。
