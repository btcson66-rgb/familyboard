# FamilyBoard 儲存無法開啟教學：先保護本機家庭資料再排查

當 FamilyBoard 顯示無法開啟本機儲存時，第一步不是重設、清除網站資料或反覆重新整理，而是停止可能破壞資料的排查。這個訊息只表示目前瀏覽器在當下無法開啟網站的 IndexedDB 資料庫，不能證明資料庫已空白、家庭資料已毀損，也不能證明雲端有另一份副本。FamilyBoard 將資料留在目前使用的瀏覽器，因此清除網站資料、刪除設定檔、解除安裝 PWA 或使用無痕視窗，都可能讓唯一的本機副本更難找回。請把錯誤當成一項存取觀察，先保護復原路徑。

## 先記下實際看見的訊息

寫下發生時間、瀏覽器名稱與版本、作業系統設定檔、FamilyBoard 網址和畫面上的原文。也記下當時是否離線、剛完成版本更新、磁碟空間不足、使用無痕視窗或同時開了很多分頁。不要一邊編輯紀錄一邊連續重新整理，也不要把含有家庭名稱、文件位置或聯絡人的完整截圖貼到公開聊天室。可以使用 `STORAGE-OPEN-2026-A` 這類中性事件代號，讓另一位家人討論狀況時不必複製私密內容。

錯誤畫面和資料狀態是兩件事。你可以寫「上午十點二十分，Chrome 某設定檔顯示無法開啟儲存」，不要直接寫成「所有資料都消失」。前者是可回溯的觀察，後者是尚未證實的結論。之後每次嘗試都加上時間和結果，避免把不同設定檔的結果混在同一條紀錄。

## 保留原本的瀏覽器設定檔

不要先清除 Cookie、網站資料、IndexedDB、下載資料夾或整個瀏覽器設定檔。也不要先解除安裝 PWA，或在無痕視窗中開啟成功後，就把那個結果當成原本家庭資料已恢復。可以先關閉重複的 FamilyBoard 分頁，保留原設定檔不動，再依 App 顯示的支援瀏覽器建議做最小範圍檢查。如果是共用裝置，先詢問設定檔擁有者，再改變權限或儲存設定。

新瀏覽器能開啟空白 FamilyBoard，只表示新環境可以建立或開啟自己的儲存，不代表原設定檔的家庭已損壞，也不會自動帶來原資料。若你在新環境建立同名家庭，未來會增加判斷混亂。測試環境應明確標示為「空白測試」或「復原副本」，不能取代原本裝置的證據。

## 在隔離環境檢查既有備份

如果已經有經過驗證的 JSON 備份，可以在受控的復原設定檔或備用裝置中開啟。先確認檔案格式、匯出日期、家庭名稱，再抽查一筆設備、一項未完成任務、一個事件、一筆保養和一個文件指標，不要編輯原本瀏覽器。成功還原只證明備份檔案可讀，不能證明發生錯誤的瀏覽器資料庫一定已毀損。

如果沒有備份，不要把畫面上的幾個標題複製成假復原檔，也不要請別人猜測密碼後連續嘗試。保留裝置和原設定檔，將問題維持為待處理狀態，再尋求熟悉瀏覽器或平台的專業檢查。任何可攜式副本都要記下建立時間、用途和保護位置；「下載過檔案」不等於「已經可以復原」。

## 分開理解配額、權限與資料庫訊號

儲存用量、瀏覽器配額、持久儲存權限和最後一次 JSON 匯出日期回答不同問題。配額警示可能說明寫入受限，卻不能指出哪一筆紀錄成功保存；無痕模式可能阻擋 IndexedDB，卻不代表一般設定檔也失效。可以到儲存健康頁查看觀察到的訊號，並以事件代號記下，不要把「資料庫沒有開啟」升級成「所有紀錄都不存在」。

如果錯誤只在某一台裝置出現，先比較瀏覽器版本、設定檔、離線狀態和最近的更新時間；如果每個設定檔都失敗，則更需要保留備份與裝置現況。不要把清除資料當成配額整理的捷徑，因為清理和刪除是不同風險。任何涉及瀏覽器政策、磁碟故障或資料庫修復的判斷，都應交給適當的技術來源。

## 需要交接時只分享最小資訊

若要向支援人員或家人說明，提供瀏覽器版本、發生時間、中性錯誤代號、頁面訊息和不含私密資料的重現步驟。完整聯絡人、地址、醫療備註、帳務資料、憑證、備份密碼和原始文件位置，都應留在受保護來源。FamilyBoard 不需要帳號，也不會默默上傳恢復副本；不要因為想求助，就把完整家庭匯出檔直接傳到公開群組。

未來若在排查步驟外出現儲存媒體或密碼管理器的聯盟商品區塊，應清楚揭露並可跳過。商品不能修復瀏覽器資料庫、保證檔案可恢復或取代免費的驗證流程。真正有用的交接是讓接手者知道哪個設定檔仍保留、哪一份備份已驗證、哪個問題尚未回答，而不是讓他取得整個家庭檔案。

## 什麼時候才可以結束事件

事件結束前，逐項記錄實際測過的結果：原設定檔是否再次開啟、備份是否可讀、隔離設定檔是否成功還原，以及哪一項仍待確認。新建空白家庭能開啟，不代表原資料已經安全；因此不能用空白畫面結束事件。保留原設定檔直到家庭決定要修復瀏覽器、執行受控還原或進行有核准的重設。

資料無法開啟時最重要的順序是「觀察、保留、驗證、再決定」。只要仍有未驗證的唯一副本，就不要為了讓錯誤消失而按下破壞性按鈕。這樣的流程雖然比清除後重新開始慢，卻能讓下一個人知道哪些事真的發生過，也能避免把瀏覽器問題誤寫成家庭資料的結論。

**情境 CTA：** 記下瀏覽器觀察、保留原設定檔，在隔離環境驗證既有備份，核准復原方案後才考慮清除資料。
