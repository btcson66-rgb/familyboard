# FamilyBoard 首次啟動復原教學：在新瀏覽器開啟既有家庭

在新瀏覽器開啟 FamilyBoard 時，不必先建立空白家庭再手動複製每筆資料。啟動畫面提供「還原既有家庭」，接受 FamilyBoard JSON 備份，先驗證套件，再在空白的首次資料庫使用取代還原。這是本機裝置設定，不是註冊帳號或雲端搬遷。還原完成並檢查前，請保留原始備份和它的保存位置。

## 先找對完整檔案

從受控備份位置找出最近且完整的 JSON，先核對家庭名稱、匯出日期和預期範圍。明文 JSON 可以直接讀取；加密檔案需要匯出時設定的密碼。不要把家庭總表 CSV 當成首次復原包，CSV 是複查與大量編輯格式，不包含完整災難復原所需的所有資料。若不確定哪一份完整，先保留候選檔並作出決定，不要在新瀏覽器反覆建立空白家庭。

## 使用啟動流程的驗證邊界

在啟動畫面，只有選到加密檔時才輸入密碼，再選擇備份檔。FamilyBoard 會解析明文 JSON，或在瀏覽器內解密通過驗證的加密套件。寫入前會先檢查格式。密碼錯誤、檔案破損或架構不支援時，應看到錯誤而不會更動啟動狀態；請回到受控來源確認檔案與密碼，不要為了測試而建立多個空白家庭。

## 檢查剛還原的本機狀態

成功後先看家庭名稱、成員角色、近期任務、行事曆事件、維護列、文件位置參照和附件中繼資料。確認目前使用的是預定裝置，敏感位置仍指向授權來源。App 不會上傳紀錄，也不會自動通知其他家庭角色。若備份偏舊，列出要從較新來源補回的資料，不要把舊狀態當成最新狀態。

## 建立下一個復原點

完成檢查後，再匯出一份新的 JSON 並保存到瀏覽器之外。若裝置會共用，依家庭隱私規則保護瀏覽器設定檔。瀏覽器資料仍可能被清除、設定檔可能消失、裝置也可能故障；首次啟動成功不代表資料已經耐久保存。日後若出現儲存媒體或密碼管理器聯盟窗格，會清楚揭露並可略過，商品不能建立同步或找回遺失檔案。

建議在交接紀錄留下「使用的檔案、驗證日期、抽查項目、下一次匯出人」。如果新瀏覽器與舊裝置同時存在，兩邊都不要立即大量編輯；先選定哪一個是主要家庭狀態，再用明確的合併或取代規則處理差異。這能避免新裝置看似成功、實際上卻讓兩份資料各自漂移。

首次還原後可以做一個小型演練：關閉並重新開啟瀏覽器，確認家庭仍能載入；再使用唯讀驗證讀取剛匯出的 JSON。這不是破壞性測試，也不會證明所有裝置風險都消失，但能讓家庭知道資料確實位於預定設定檔，以及下一次復原需要哪個檔案與角色。若看見資料不一致，先保留新舊兩份副本並記錄差異，不要立刻清除舊裝置。

也要向使用者說明首次啟動不會建立帳號、推送通知或替家庭聯絡任何人。需要同步的部分必須透過家庭自己控制的安全來源交接；FamilyBoard 只提供本機資料結構和驗證後的還原動作。當裝置要交給別人時，先匯出、確認副本，再依瀏覽器政策清除本機資料，並保留清除前的觀察紀錄。

若家庭使用多個瀏覽器，請在交接表標示每個設定檔的角色和最後驗證日期，避免把其中一個成功還原誤認為所有裝置都已同步。FamilyBoard 沒有替你合併多台裝置的背景服務，差異必須由家庭自己確認。

若家庭使用多個瀏覽器，也請在交接表標示設定檔角色與最後驗證日期；一次成功還原不代表其他裝置已同步。差異要保存副本後由家庭自行確認。換機前把這份交接表和備份位置一併交給下一位負責者，並註明誰有權限讀取。

**情境 CTA：** 在乾淨瀏覽器找出一份完整 JSON，透過啟動流程還原，抽查代表性紀錄後匯出下一個復原點。
