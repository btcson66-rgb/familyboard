# 可列印家庭服務商清單：記住做過什麼，不把一次合作當成永久推薦

家庭常在最忙的時候才需要找水電、冷氣、家電維修、鎖匠、清潔、搬運或社區管理聯絡。這張表的目的，是讓家人知道服務類別、公司或人員、目前可用的聯絡管道、曾經處理的範圍和最後一次確認日期。它不是公開推薦榜、施工品質評分或資格證明；曾經合作過只表示有一段歷史，重新聯絡前仍要確認營業狀態、服務區域、報價、保固與合約。

| --- | --- | --- | --- | --- | --- |

| 冷氣／暖氣 |  |  |  |  |  |

| 社區／房東 |  |  |  |  |  |
| 清潔／搬運 |  |  |  |  |  |

聯絡管道欄可寫官方網站、客服入口或家庭受控通訊位置，不必把私人手機、完整住址、門禁碼、帳號或付款資料複製到會被訪客看到的紙本。處理範圍欄使用 `AC-01`、`KITCHEN-02` 這類中性代號即可；詳細報價、收據、合約、照片和服務對話放在家庭已經信任的受控位置。

## 從一次實際工作開始填

選一個最近完成或仍在等待的工作，寫下「何時聯絡、誰回覆、做了什麼、結果如何、還缺什麼」。把「修好了」拆成可觀察結果，例如「客廳冷氣滴水，8/12 聯絡原廠，8/14 到場清潔，8/20 再觀察」。若仍等待零件、報價、回訪、退款或保固確認，狀態要寫清楚並指定負責人與日期，不要用勾選掩蓋未完成。

涉及漏電、焦味、瓦斯、快速漏水、結構、屋頂、高處或其他危險工作時，清單只保存安全距離可見的觀察與通知進度，不提供自行拆修或施工指示。合約責任、保固、保險、租約和業者資格要回到原始文件、主管機關或合格專業人員。服務商名稱旁邊不應寫未查證的「最便宜」「一定可靠」或「保證安全」。

## 更新與交接

每次電話、網站、服務範圍、公司名稱、搬家或家庭角色改變時，標註新複查日期並保留舊紀錄。讓另一位家人使用這張表找出「目前誰可以處理、哪個設備曾被處理、哪份來源仍要確認」；若對方必須問建立者，補的是欄位或來源，不是把所有私密細節公開。需要長期追蹤的服務歷史可放入[繁中 App](/zh-tw/app/)的資產與保養紀錄，紙本保留為短期交接。

未來公開頁若出現工具箱、收納或聯絡管理用品推薦，會位於主要清單之外並揭露 affiliate 關係；推薦不是業者背書，也不會出現在私密 App 或生成紙本。

## 服務商查找演練

完成第一列後，請另一位家人用三十秒回答四件事：這位服務商處理過什麼、最後一次何時確認、目前用哪個聯絡管道、若沒有回覆下一步找誰。若答案只能靠建立者口頭補充，就在表上增加來源、複查日或備援角色。把「曾經使用」和「目前已驗證」分成兩個欄位，因為公司名稱、電話、營業區域、服務範圍與報價都可能變動。

每次叫修後新增一筆事件，不要覆蓋原列。寫下可觀察症狀、通知日期、到場結果、收據或照片代號、保固／回訪狀態和負責人；不要把服務商的猜測改寫成家庭自己的診斷。涉及電氣、瓦斯、結構、屋頂、門禁或高處工作時，清單只保存聯絡進度，不能指示自行拆修。服務商資訊若要交給房東、家人或照顧者，先刪除不必要的私人電話、住址、付款和帳號，並在合作結束後回收紙本。

若服務商停止營業或資料失效，在新版本標註「不再使用」與查證日期，保留舊紀錄以便追溯，不要靜默刪除歷史。FamilyBoard 的本機資產與保養紀錄可連結這張表，但仍須定期匯出備份；任何公開推薦都只是可選類別，不代表表上的業者或商品獲得背書。

交接給別人前，再核對一次服務範圍、地區、可接受的聯絡時段與誰有權發出委託；不確定的欄位標為待確認，完成後才更新版本。
