# 可列印清潔排程表：先維持住家，再把工作分給真正有時間的人

好的清潔排程不是把每個角落都塞進日曆，而是讓家庭知道今天最低要做什麼、這週誰負責什麼、哪些工作可以輪替。先寫版本日期、住宅區域、參與者與複查日，再刪掉沒有的房間、設備或不適用的頻率。排程只協助安排家務，不提供化學品混用、電氣拆卸、高處作業或黴菌處理指示；安全與產品使用要回到標籤、原廠和合格專業來源。

## 三層排程

### 每日最小重置

| --- | --- | --- | --- | --- |
|  |  |  |  |  |
|  |  |  |  |  |

只放會影響隔天生活的項目，例如食物收好、垃圾移到指定處、常用區域恢復可用。完成標準要可觀察，像是「餐桌可用、廚房地面沒有新溢出物」，不要寫「保持整潔」這種無法交接的句子。若當天時間不足，記錄延後原因和下一步，不用用未完成的勾選假裝清潔已結束。

### 每週工作

| 房間／區域 | 工作 | 負責人或輪值 | 預定日 | 來源／備註 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |
|  |  |  |  |  |
|  |  |  |  |  |

把清潔、補充用品、洗滌、回收和檢查設備濾網分開列，因為它們的完成標準不同。若涉及濾網、電器、瓦斯或高處，排程只寫「依手冊確認」與負責聯絡的人，不把通用網路週期當成所有設備的固定要求。遇到漏電、焦味、快速漏水或不明化學氣味，停止不安全操作並尋求適當協助。

### 輪替深度工作

| 工作 | 上次完成 | 下次複查 | 負責人 | 是否仍適用 | 備註 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |
|  |  |  |  |  |  |

深度清潔不應全部集中在同一週。依住宅大小、家庭成員、寵物、季節、濕氣和實際使用輪替；每次只增加一項真正有理由的工作。兩次以上無法完成時，先縮小範圍或改變頻率，並記錄「為什麼」而不是責怪某個人。

## 檢視公平與可持續性

每週請家人一起看三件事：工作是否仍適合目前生活、是否有看不見的採買與行政負擔、哪些項目一直被延後。不要只計算擦了幾次地，還要看到補充用品、預約、收拾、提醒與善後。可將需要長期追蹤的任務移到[FamilyBoard 繁中 App](/zh-tw/app/)，紙本留作冰箱、會議或短期交接用途。

未來公開頁若有掃具、收納或計時用品推薦，會放在排程之外並清楚揭露 affiliate 關係；不會插入私密 App、生成結果或列印表，也不會讓忽略推薦的人失去免費功能。

## 用一週實際結果調整

第一週只填每天最小重置、每週一項和輪替一項，完成後在「實際結果」寫下花費時間、卡住原因和誰需要支援。若同一項連續兩次延後，先確認它是否太大、頻率太高或完成標準不清，再拆成「準備」「執行」「收尾」或換到較合適的日子。不要用增加提醒或扣分來掩蓋排程本身不符合家庭生活。

清潔工作的隱形部分也要列出，例如補充垃圾袋、購買清潔用品、預約專業服務、收拾工具和處理異常。這些不一定由實際擦拭的人完成，若沒有記錄，排程會把管理責任固定在同一個人身上。每月複查一次房間、寵物、氣候、工作時間和設備變化，回收舊版紙本；需要長期追蹤的項目再轉成 App 任務。涉及化學品、電氣、瓦斯或高處作業時，停止自行嘗試並依標籤、手冊與專業來源處理。

最後由一位沒有排表的人試著接手一天，記錄哪些欄位真正有幫助、哪些只是裝飾；下一版只保留能改變行動的資訊。

排程更新時保留舊版的完成結果，方便知道是生活改變，還是原本的頻率不合理。

把每次調整的原因寫入備註，下一位負責人才能理解這個週期不是隨意設定。

若季節、寵物或住家人數改變，也要重新檢查區域和工作量。

可以在複查欄記錄「本週實際花費」「是否需要協助」「下次想調整的地方」。這些簡短資料比追求漂亮的滿表更能幫助家庭找到適合自己的節奏；當工作轉交給新成員時，也能說明為什麼某項安排被保留、縮小或暫停。
