# 可列印看家照護清單：讓短期代班者知道每天要做什麼、何時求助

看家交接不是把整個家庭的生活細節複製給別人，而是讓獲得授權的人在指定日期內完成最低必要工作，知道哪個變化要回報、哪個問題要停止自行處理。這張清單適合出門旅行、住院陪伴、臨時照顧或請朋友代收物品；它不取代合約、獸醫指示、房屋管理規則或緊急服務。列印前先寫家庭代號、適用日期、建立者、看家者與版本日期，並把帳號、密碼、門禁碼和完整住址放到分開且受控的交接管道。

## 先定義範圍與權限

| 欄位 | 填寫內容 |
| --- | --- |
| 看家日期 | __________ 至 __________ |
| 看家者與可聯絡時段 | ______________________________ |
| 家庭主要聯絡人 | ______________________________ |
| 備援聯絡人 | ______________________________ |
| 可以處理的範圍 | 例如收信、澆水、餵食、倒垃圾 |
| 不可自行決定的事項 | 例如修繕、付款、改變用藥或邀請訪客 |
| 版本／回收日期 | ______________________________ |

把「可以進入」和「可以決定」分開寫。看家者可能有鑰匙，卻沒有權限更換鎖、承諾費用或把資料轉交他人；若授權不清，保留問題並聯絡主要角色，不用猜測。

不要只寫「照顧貓」或「保持整潔」。寫出可觀察的結果，例如「晚餐後確認水碗仍可使用，若看見異常拍照並聯絡飼主」；但不要把清單變成醫療或危險設備的操作指示。需要用藥、特殊飲食、電器或瓦斯時，附上已確認來源的代號與聯絡角色，讓看家者知道應該問誰。

服務預約存在不代表工作已完成。請把「人員到過」「看家者看見什麼」「哪個結果仍待官方確認」分開記錄；不要要求看家者簽收不存在的工作，也不要把包裹顯示 delivered 當成內容完整。

## 異常升級與結束交接

若發現漏水、異味、受傷、入侵跡象、停電、設備警示、寵物異常或物品遺失，先離開危險範圍，使用家庭已批准的升級順序與所在地官方服務。清單上只寫：觀察時間、位置代號、已聯絡角色、對方回覆來源與下一次複查時間。不要要求拍攝暴露個資的影像，也不要在紙上留下門禁或醫療細節。

離家結束時，請看家者和家庭主要角色共同確認：鑰匙或物品已交回、未完成工作仍列為 open、包裹和垃圾的狀態有來源、紙本敏感副本已回收。若對方沒有建立者在場也能說出下一步，才算完成一次交接演練。長期重複的任務可放入 FamilyBoard 本機 App，紙本保留給短期、離線和現場走讀；任何推薦用品都應置於清單之外並清楚揭露 affiliate 關係。

## 出發前的十分鐘演練

請找一位沒有參與製作的人，給他這張表和必要的受控交接資訊，請他依序回答：今天先做哪三件事、寵物或植物異常要問誰、哪個區域不能自行進入、服務商延誤如何留下來源。若他必須一直回頭問建立者，表示角色、用途或版本日期不夠清楚，先修改欄位再離家。演練只用低風險的假設情境，不要真的關閉電源、測試瓦斯或讓寵物改變飲食。

## 回家後的紀錄與版本管理

回家時不要直接把所有勾選改成完成。先核對看家者寫下的觀察、照片代號、服務通知與未解決問題，再由有權限的人確認哪些結果已被官方來源支持。若少了一件包裹、植物狀況改變或鑰匙交接時間不清，保留原始版本並新增一列追蹤，記錄負責角色與下一次複查。紙本若含住址、門禁、行程或寵物醫療資訊，回收後依家庭的安全處理方式保存或銷毀；不要把影像貼到公開群組。這樣下次出門時，新的清單會從已核對的事實開始，而不是把上次的猜測複製下去。
