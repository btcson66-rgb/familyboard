# Household Event Source Index Log

An event record becomes difficult to trust when a family remembers the observation but cannot identify where the supporting notice, photo, manual, provider reply or protected file lives. This free browser tool creates one dated index row so the next person can distinguish a household observation from a responsible source. It is deliberately narrow: it does not copy documents, upload photos, authenticate a website or decide what an event means.

## What to enter

Use a short code such as `OUTAGE-A`, `LEAK-2` or `SERVICE-APRIL`, then enter the date you actually checked the source. Describe the source's role rather than claiming a conclusion: `building notice / restoration update`, `manufacturer manual / installation section`, or `provider reply / arrival record`. In the evidence field, keep a pointer to a protected original and a minimal observation, such as `OBS-1; photo set A3; damp patch visible from hallway`.

The final field is one next action and owner. “Recheck current notice version | household administrator” is useful; “fix the leak” is a decision the tool cannot authorize. A clear owner lets another family member continue the work without receiving the whole private file.

## Keep four layers separate

The event code identifies the household record. The responsible source says who issued or controls the information. The observation says what someone actually saw or what the protected file points to. The next step says what remains to be checked. Do not collapse these into a single sentence such as “the building caused the leak” or “the appliance is safe.” Those are findings that belong to the responsible source or a qualified professional, not to an index.

If you also need elapsed time, use the [Household Event Duration Calculator](/tools/household-event-duration-calculator/) for two observed timestamps and copy the result back with both source descriptions. If the event has many dated changes, the [Repair Evidence Timeline Log](/tools/household-repair-evidence-timeline-log/) can hold a fuller sequence. The source index remains useful for one disputed or easy-to-lose pointer.

## Version instead of overwriting

An old source may still matter to an unresolved complaint, repair, claim or handoff. Keep the check date and a safe version marker when the issuer provides one. When a link redirects, a notice is replaced, the protected file moves, a new person takes ownership or the event scope changes, create another row or version. The index does not make a downloaded copy permanently current.

## Privacy and sharing

The form runs in the current browser and does not send fields to FamilyBoard. Do not paste addresses, phone numbers, account IDs, passwords, access codes, medical details, complete contracts or private messages. A pointer is not a substitute for protecting the original. Before sharing an index, remove anything that lets an unintended reader identify a household, person, provider account or exact location.

A paid link cannot authenticate a source, alter a status, select a provider or replace the controlling document. The source index and its next action remain complete without a purchase.
