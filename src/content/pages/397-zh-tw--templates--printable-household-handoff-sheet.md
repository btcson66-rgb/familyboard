# 可列印家庭交接表：讓責任換手，而不是把一堆資料丟給下一個人

出差、住院、照顧家人、搬家或家庭角色更換時，問題通常不是沒有資料，而是接手人不知道這一週要先做什麼、做到哪裡算完成、可以看哪些資料、何時不再需要權限。這份表把範圍縮到一個人、一段期間和一組明確工作；它是溝通與複查工具，不是授權書、契約、緊急服務替代品，也不是複製完整資料庫的方法。

## 範圍、期限與未來 30 天

寫下交接目的、生效日期、到期／複查日期、準備人、接手角色與不處理的範圍。短期代班和正式移交不能共用「直到需要為止」；到期是逐項收回臨時權限、刪除副本或重新產生版本的控制點。

|---|---|---|---|---|
| | | | | □未開始 □進行中 □已完成 |
| | | | | □未開始 □進行中 □已完成 |
| | | | | □未開始 □進行中 □已完成 |

一列只放一個能驗收的工作。「處理帳單」應改成核對某筆已授權帳單的到期日並回報單據位置；「照顧房子」應拆成檢查、聯絡與回報。遇到立即危險，先離開並使用所在地官方緊急服務或合格專業協助，不要等待紙本。

## 責任、問題與聯絡來源

把誰做和誰負責發現該做分開。若工作涉及瓦斯、電氣、屋頂、結構、污染水、醫療、法律或金融判斷，接手人只能負責找到適當來源，不要把專業工作偽裝成勾選項目。問題欄只寫可觀察事實和可靠來源，例如「洗衣機右側地面於 8/29 18:10 可見水痕，照片 ITEM-02，已通知房東」，不要把診斷或保險結論寫成已確定。

聯絡欄要寫用途、角色、核對日期和何時使用。電話、電子郵件、服務入口和社區公告可能改變，交接前應再確認；真正的緊急聯絡以所在地官方資訊為準。

## 納入、排除與小測試

明寫本次納入的近期任務、已授權帳單日期、住宅服務聯絡和完成證據位置，也明寫密碼、驗證碼、門禁碼、完整金融資料、證件、與本次無關的醫療／法律資料不在授權範圍。紙本、下載檔和聊天照片都可能轉傳，秘密不能藏在備註欄。

把表交給接手人，請他在不靠口頭提示下找出一個未來 30 天期限、一個合法聯絡來源和一份完成證據。若只能說「再問你」，就修改觸發、角色、來源或證據並記下修正日期。演練不要延遲付款、關閉服務、操作高風險設備或分享正式密碼。

到期時把每列分成已完成、轉回原負責人、需要延長並重新確認；核對服務結果、回收鑰匙與設備、撤除臨時存取並刪除不再需要的副本。正式角色移交還要確認新負責人能獨立找到文件、使用自己的正式權限並取得可用備份。
