# Launch external actions

This record separates code readiness from provider state.

- GitHub repository and Pages: performed through the authorized company GitHub account; status in `LAUNCH_REPORT.md`.
- Cloudflare DNS: performed through the authorized company zone; status in `LAUNCH_REPORT.md`.
- GA4: requires Admin API or authenticated Analytics UI access to create a separate property/stream.
- GSC: requires authenticated Search Console ownership/API access and a live HTTPS site before sitemap submission.
- AdSense: reuses the company's single publisher account. The public account meta/ads.txt can establish ownership, but Google review state must be read back from AdSense.
- Affiliate: public cards stay inactive until the owner supplies a valid program tag. No placeholder or untracked shopping URL is presented as an affiliate product ad.
